## 必须先解决的事项

实际面板与描述符分辨率不一致；2400高度超过原最大声明2047；现有CDC启动与目标AD11/ADA0双态不同；HID/Caps/ACK契约未完成；示例MJPEG分片头长边界错误；USB短包/ZLP和parser reset范围需要实机核验；正式驱动绑定与安装需提前验证。

两个交付边界：R0仅为内部主题态版本；R1必须有完整HID双模、纯熄屏、正式安装和实机恢复验收。触摸、镜像、多设备、OTA与动画下发独立进入R2候选，不是首版隐含承诺。
