# USB Display 上位机

版本：v0.2 全面重写稿　日期：2026-10-06

本项目面向 AD100 与 VTDR6115 1080×2400 屏幕，开发 Windows 原生桌面上位机，提供主题显示、设备控制、硬件信息展示和主题态／副屏态切换。

本版包含需求分析、PRD、软件技术架构、项目管理和项目规范五份文档。

## 技术方向

- C# / .NET 10，WPF + XAML 原生桌面界面，MVVM 组织交互。
- 单进程本地运行；Windows WinUSB 与 HID API 负责通信。
- 独立内容模型，通过 WPF DrawingVisual / RenderTargetBitmap 离屏绘图，再编码 JPEG；不截取管理窗口。
- 原生绘图和编码先做真实屏幕验证，验证不通过时仅替换有问题的渲染或编码模块。
- JSON 本地配置、本地日志、仓库内任务与验收记录。

以上是本次提出的实现基线；编码器兼容性、固件能力和驱动绑定仍须样机验证。仓库目前只有文档，未实现应用。

## 交付边界

内部验证版完成主题态出图、配置与恢复；正式首版还须完成 HID 双向控制、双模切换、纯熄屏和安装验证。内部版本不能代替正式双模产品。

触摸、桌面镜像、OTA、开机动画下载、多设备同时推流和主题编辑器列为后续候选。本版不承诺 30/60fps，不以源文中的性能陈述代替实测。
