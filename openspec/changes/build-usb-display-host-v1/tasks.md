# USB Display 上位机 0→1 实施任务

本清单全部为待实施任务。编号 X.Y 用于 OpenSpec 跟踪，括号中的 T-xx 对应 [项目管理](../../../docs/04_项目管理.md)；验收编号定义见 [项目规范](../../../docs/05_项目规范.md)。架构与行为分别见 [design.md](design.md) 和本变更 `specs/` 下九项能力。

完成一个复选框需要其实现或交付物及所列验证同时具备。模拟、Windows 适配、真实窗口、硬件与安装记录分别保留；硬件输入缺失时保持未勾选，记录提供方、阻塞影响及下一次确认时间。证据计划存入 `docs/verification/`，契约存入 `docs/contracts/`，交付说明存入 `docs/release/`；这些目录由实施任务按需创建。

可以立即开始 1.1、2.1～2.4；3.x 的 UI 基础在 2.x 后先行。1.2～1.5 为外部事实与协议依赖，不能由模拟关闭。2.5 和 12.1 的发布机制试验可提前进行；11.x 控制面在匹配固件交付后开展，不必等 V0 发布。各组的“依赖”优先于章节顺序，组内按列出顺序推进，注明可独立者除外。
