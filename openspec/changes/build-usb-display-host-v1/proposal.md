# USB Display 上位机 0→1 提案

## Why

USBDisplayHost 当前只有 v0.5 设计文档，尚无应用工程；设备发现、主题出图、双模控制到安装更新的完整链路尚未实现。本变更把现有文档转为可实施、可追踪、可验收的首版建设计划，交付面向 AD100／VTDR6115 1080×2400 屏幕的 Windows 原生上位机。

## What Changes

- 建立 .NET 10、WPF/XAML＋WPF UI、CommunityToolkit.Mvvm 工程基线，以及构建、测试、依赖锁定和发布入口。
- 实现单台选定设备的发现、身份匹配、能力核验、WinUSB 会话、热拔插和休眠恢复；多台接入时不自动接管其他设备。
- 实现完整 JPEG 内容生成、0xAF 分片传输、最新帧调度和有界恢复，完成图片、时钟、基础仪表盘三个模板及一致预览。
- 实现设备、主题、设备设置、应用设置、诊断五个页面，以及托盘、单实例、可选自启、紧凑布局、高 DPI 和可访问性。
- 分开管理草稿、当前会话配置、本地恢复配置与设备反馈，分别报告发送、保存和呈现结果。
- 在冻结的固件契约上实现两态 HID、亮度、双向模式切换及不复位的纯熄屏／唤醒。
- 实现本地配置与素材、分源指标、有限日志及诊断导出；完成 Velopack 安装、用户发起的软件更新和失败修复流程。
- 按 G0→M1～M5 推进：G0 关闭协议和环境前置项，M1 最小出图，M2 稳定会话，M3 形成内部 V0，M4 完成双模控制，M5 验收正式 V1。纯逻辑和 UI 可先行，硬件验收单独保留完成证据。

V0 是内部主题链路验证阶段，至少完成 1 小时稳定性实验；V1 必须补齐双模、纯熄屏、安装更新及 24 小时长稳。缺少固件、驱动或实机证据不能将 V0 认定为正式首版。

首版不包含触摸、桌面镜像、视频播放、设备固件 OTA、开机动画下载、主题编辑器／市场、并行多设备推流、rlx 局部刷新、30／60fps 承诺。副屏桌面由厂商驱动输出；软件更新只更新上位机。

## Capabilities

### New Capabilities

- `desktop-workspace`: 五页原生工作区、可信状态与预览、高 DPI、键盘及可访问性。
- `application-lifecycle`: 单实例、托盘、自启、关闭／退出策略和有界资源清理。
- `device-session-management`: 选定设备、稳定身份、兼容校验、会话互斥、重连和休眠恢复。
- `jpeg-frame-transport`: 握手、JPEG 校验与分片、单写者、限流和部分写恢复。
- `theme-content-rendering`: 三模板、物理尺寸与旋转、独立渲染、预览隔离和有界编码。
- `profile-application-storage`: 草稿／活动／恢复配置、首帧应用事务、本地素材及损坏恢复。
- `device-controls`: 冻结 HID 契约上的亮度、模式切换、电源控制及真实结果确认。
- `telemetry-diagnostics`: PC／设备指标、过期与缺失状态、传输统计、错误号和诊断导出。
- `application-update-delivery`: 离线安装、检查／下载／安装更新、配置迁移、修复及正式发布准入。

### Modified Capabilities

无。当前 `openspec/specs/` 没有已有能力规格；本变更全部为新增能力。

## Impact

- **代码与依赖**：计划新增 Desktop、Core、Windows、Rendering 四个生产工程及对应 MSTest 项目；SDK、WPF-UI、MVVM Toolkit、Serilog、Velopack 具体版本在建项和实验中锁定。Core 保持平台无关，正常运行保持单进程。
- **系统与硬件**：首版目标 win-x64；Windows build、固件／驱动版本、VID/PID、HID 报告、JPEG 支持范围、ZLP 与 parser reset 必须通过冻结记录及样机试验确认。固件与驱动工作由相应协作方交付，本仓库负责主机及集成验收。
- **本地数据与发布**：新增当前用户独立数据目录和受控 HTTPS 稳定更新源；日常核心功能离线运行，不依赖账号、业务服务器或数据库。域名、签名与驱动分发条件仍是待落实输入。
- **追踪依据**：以 [README](../../../README.md) 和 [需求分析](../../../docs/01_需求分析.md)、[PRD](../../../docs/02_PRD.md)、[架构](../../../docs/03_软件技术架构.md)、[项目管理](../../../docs/04_项目管理.md)、[项目规范](../../../docs/05_项目规范.md)、[UI 规范](../../../docs/06_UI设计规范.md) 的 v0.5 基线为准，保留 REQ／FR／T／TC／NFR 编号。原始参考资料是来源陈述，冲突按 Q-01～Q-16 关闭，不直接作为已验证实现契约。
- **排期与完成口径**：本提案覆盖完整 0→1，不承诺日历交付日期。原 27～42 人日仅为粗估，UI 细化与软件更新需重新估算；模拟、桌面截图、USB 完成和真实屏幕证据分别记录。
