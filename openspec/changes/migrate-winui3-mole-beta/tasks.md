- [x] 1.1 建立 WinUI 非 MSIX 自包含宿主和五页导航骨架。PR #16 的 `d49b252` 通过 PR 规范、Windows 构建、HeyDeer 和独立代码审核，已处理两条旧意见。PR 仍为草稿。
- [x] 1.2 Beta 5 在断网 Windows 10 LTSC 21H2（19044.1288）默认工作区实测 Tab、方向键与空格，两种导航均可打开五页。通过键盘切换布局、滚动到主题属性与更新设置、打开和取消原生文件选择器、确认保存后退出。Beta 2 此前通过关闭至托盘后重复启动激活同一进程。

## 2. 设备会话（#10、#15）

## 3. 五页功能（#11–#14）

- [x] 3.1 集成主题、设备设置、诊断和应用设置。集成代码已编译；离屏渲染通过 9 项 JPEG、四方向、1920×1080、取消和尺寸预算验证。修复 WIC 在 1 字节预算下返回零字节成功的问题。设备设置已修复旧会话异步结果串代次。

## 6. 整体验收

- [x] 6.1 Beta 2 的浅色五页功能与 Beta 5 的深色双导航五页均使用实际安装版实拍并双人只读复核。Beta 5 修复 1024×768 默认工作区顶部主题首屏的模板名称裁切，实测侧边主题与应用设置的键盘滚动并进入控件，检查取消选图和保存后退出。Windows 10 LTSC 单客体、4 个仿真核、6 GiB、断网无设备，各运行 3 次并交错启动。由进程启动到可见主窗口的中位数，WPF 0.1.4 为 15.22 秒，Beta 5 为 9.74 秒。启动后 6 秒采样的工作集分别为 127.4、135.3 MiB，私有内存分别为 55.4、48.4 MiB。Beta 5 在全新应用配置下首次显窗 11.48 秒。上述时间覆盖该仿真客体的进程首次及重复启动。
- [x] 6.2 从微软原始 Windows 10 LTSC 21H2 评估镜像新建断网客体。安装前确认缺少全局 .NET Desktop Runtime、Windows App Runtime 框架包和旧用户数据。Beta 4 初次安装，Beta 5 用全新应用配置重装，均打开原生窗口并加载包内 .NET／WinUI。Beta 5 与 WPF 0.1.4 同时运行。卸载 Beta 后保留 Beta 偏好，正式窗口仍运行，正式清单与偏好校验值一致。最终 Beta 5 Release 编译 0 警告、0 错误，安装包 5 个产物摘要一致。
- [ ] 6.3 获准后用指定 USB 设备验收枚举、连接、真实显示、旋转、应用和本地保存、断开重连、接口占用及退出恢复。记录设备型号、固件、接口和最终结果。本轮设备枚举未检测到目标型号。
- [ ] 6.4 配置并发布独立 Beta 更新源后，用实际 GitHub Release 检查、下载、校验和重启安装，并复核正式 Latest。公开发布独立决策。
