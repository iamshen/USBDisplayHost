## 软件验证

- `./build.ps1 -Action Build` 使用 .NET SDK 10.0.401 完成锁定 Release 构建。WinUI、WPF 和共享项目零警告、零错误。
- 本机回归 30 项通过，覆盖八款 JPEG、独立时间与监测刷新、旋转与帧长、取消、主题库和设备恢复、旧配置、无效坐标、素材引用和占用分类。
- `openspec validate redesign-winui3-figma-workspace --strict --no-interactive`、`openspec validate migrate-winui3-mole-beta --strict --no-interactive`、`git diff --check` 通过。

证据保留在本机 Git 忽略目录 `.artifacts/figma-redesign/`。`windows-final/` 包含无设备窗口与主题交互，`windows-scenarios-final/` 包含本机验收副本的受控状态，`reference/` 包含 Figma 导出。两次常规构建间只更新了设备页的已连接和本地交接动作，设备页已复拍。验收副本在独立目录注入受控会话，保留真实 ViewModel、命令、渲染、存储及 WinUI 窗口。构建指纹、操作记录及软件回归输出留在同一证据目录。

## 标签页视觉复核

2026-11-17 根据试用反馈，用同一台电脑的默认窗口复现顶部和侧边导航。与 Figma 导出和 `screens.js` 逐页核对后，修正了侧边导航的选中胶囊和切换时的页面跳动、设备页的当前会话对齐、设备设置的全宽亮度滑轨和按钮位置、诊断的运行详情和事件列、应用设置的配色卡和版本行，以及主题库的卡片间距。

| 实际运行 | 本机证据 |
| --- | --- |

### 父容器边距量测

顶部和侧边导航共享固定内容行。关闭的操作提示已移出布局，且在受控连接应用 4 fps 时验证提示仅在内容区出现，关闭后设置底部分隔线回到原位。诊断改为分别控制卡片、披露入口和事件表头的间隔，应用设置改为控制左右列的分隔与各行间距。

使用独立数据与独立单实例锁复拍两套配色的五个标签，以及侧边导航、主题编辑和诊断详情。截图来自同源 WinUI Release 验收副本，受控连接仅用于操作反馈核对。默认窗口截图为 1166×813，Figma 为 1180×820。未调整默认窗口尺寸或系统缩放。诊断卡片和表头上沿在修正后分别为 Y=208、437，与画板相同。应用设置中线从 X=660 移至 X=637，画板 X=646，按窗口宽度换算约 X=638。完整像素量测、对照截图与 Release 构建结果见 `.artifacts/figma-redesign/layout-insets-review/`。

### 固定顶部横向导航

用隔离数据和独立单实例锁运行同源 Release 构建。配置明确保存暖棕外观及 `navigationLayout: "Side"`，启动显示暖棕顶部导航。点击顶部设备后用右方向键依次切到主题、设备设置、诊断和应用设置，应用设置已移除布局选项。保存深蓝后关闭并重启，外观回读正确，配置中其余旧偏好一致。深蓝窗口实测鼠标切页和设备页「预览主题」快捷入口。

Release 生产构建和验收构建均为零警告、零错误。截图、交互记录和旧配置验证见本机忽略目录 `.artifacts/figma-redesign/top-navigation-only/`。

## 剩余范围
