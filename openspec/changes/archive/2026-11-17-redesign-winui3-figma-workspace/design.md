# WinUI 3 设计改版设计

## Context

交接点为候选分支的 `b052c28`。Figma 窗口基线为 1180×820，Tokens 定义两套语义配色。WinUI 入口与正式版复用设备、主题应用和更新前退出逻辑。

## Goals / Non-Goals

- 五页复用现有命令和状态，按 Figma 改造导航、信息层级和操作位置。
- 主题库与编辑器覆盖八款预设及本机保存记录。共享离屏渲染遵守设备尺寸、方向和 JPEG 预算。
- 净机安装历史留在迁移变更，当前变更核对实际窗口与本机功能。硬件和在线更新按可用环境报告。

## Decisions

1. **外观与导航**。把 Figma Tokens 映射到 WinUI 共享语义资源。配色通过现有应用设置编辑、撤销、保存和回读。WinUI 3 Beta 固定使用顶部横向导航，旧导航字段仅保留在共享配置中供既有客户端读取。
2. **主题**。在既有主题内容类型之外增加分层场景，使用设备画布坐标。素材与实时文本分离。选择框、参考线、焦点和命中处理属于 WinUI，设备输出由共享离屏渲染生成。
3. **存储**。「我的主题」是 Beta 数据根内的命名主题库。设备应用继续冻结当前编辑和会话代次，并沿用恢复配置和重试保存。已有配置按原格式读取。
4. **验证**。对照续跑资料的九张 Figma 导出图。当前构建使用隔离数据运行，记录外观、五页、预设入口、拖动、属性修改和保存重开。USB 占用和本地交接使用受控会话验证呈现，另记真实设备条件。

## Risks / Trade-offs

预设缩略图含演示时钟和监测值，只用作主题库参考。编辑和传输使用独立背景及当前时间和监测快照。运行截图会出现与 Figma 示例数据不同的内容。
