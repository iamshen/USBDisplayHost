# 配置与自动恢复

更新日期：2026-10-14。适用于当前开发版本。关联 FR-04、FR-06、FR-08、FR-10，T-16、T-18、T-19、T-30。页面实现及已有运行证据见 [全页面重排记录](verification/all-pages-redesign-2026-10-13.md)；真实设备出图与文件故障恢复仍待验收。

## 主题与设备设置

主题提供图片、时钟、仪表盘三个模板。图片支持 PNG／JPEG、完整显示和填充裁剪；未选图时使用内置背景。时钟默认 24 小时制并显示本机日期。仪表盘的 PC CPU／内存由主机采集，缺失的温度或设备指标不显示为零。

设备设置的方向、帧率、JPEG 画质属于待应用字段，默认分别为 0°、5fps、80；恢复默认只改变编辑值。亮度通过独立的滑块和精确输入“设置”即时操作，不随图像输出的恢复默认写入。设备设置在连接、主题模式、亮屏且未暂停等条件满足时开放。

## 编辑与应用

主题页只提供模板、内容参数、预览和“应用到设备”。无设备时可编辑预览，应用按钮禁用；预览本身不会发送到设备。设备设置使用“应用设置”提交方向、帧率和画质。两页均不提供草稿读取、保存或归属管理。

- 切页保留内存编辑，撤销恢复页面最近同步或成功应用的内容；退出后不恢复未应用的编辑。
- 主题页没有未应用更改时同步当前活动主题；已有编辑时保留内容，只有明确应用才发送至当前设备。
- 设备设置属于当前会话，切换设备或会话后重新读取活动参数；没有活动参数时显示默认值，不携带上一台设备的未应用输入。
- 应用期间暂停本页编辑，冻结本次内容和设备代次；旧会话的迟到结果不能覆盖当前页状态。
- 应用设置独立使用“保存设置”，导航选择可立即预览，撤销更改恢复已保存的应用偏好。
- 显式退出时，主题或设备参数尚未应用则确认是否放弃；应用偏好仍提供保存／放弃／取消。收至托盘保留内存状态。

## 应用结果

“应用到设备”冻结本次内容，首帧完整发送后更新当前会话，再保存设备恢复配置。发送完成、保存完成和设备呈现是不同结果。当前固件未提供可靠呈现反馈时，不以主机预览或 USB 完成认定屏幕已显示。

正常应用自动保存对应设备的恢复配置，不需要额外的保存步骤。发送成功但本地保存未完成时，使用该结果对应的本地重试入口；这些动作只处理配置文件，不重发主题或控制命令。保存结果未知时先核实主文件。重新连接使用已确认保存的恢复配置，不把未保存候选或未应用输入当成恢复配置。

## 数据目录与恢复

用户数据位于 `%LocalAppData%/UsbDisplayHost.Data`：

| 路径 | 内容 |
|---|---|
| `application-settings.json` | 应用设置 |
| `profiles/` | 各设备已保存的恢复配置 |
| `assets/` | 已复制的图片素材 |
| `diagnostics/logs/` | 本地结构化日志 |

设备文件名使用设备键的哈希；不要通过重命名把文件转给另一台设备。图片导入成功后不再依赖原图片路径；恢复时应同时保留配置和整个素材目录。旧版本可能存在的 `drafts/`、`device-settings-drafts/` 文件保持原样，当前页面不再读写；底层兼容接口及素材引用扫描仍保留，不能据此删除旧素材。

读取损坏主文件时，程序尝试读取可用备份并显示恢复情况；读取本身不自动重写文件，只有应用成功后的保存或显式应用偏好保存才提交新主文件。未知高版本或过大文件会阻止覆盖。保存失败／待核实时保留原目录，先查看页面错误编号和诊断，不反复保存或清除备份。

需要人工恢复时，先正常退出应用，再将整个数据目录复制到其他位置留存。确认备份与当前程序版本兼容后，保留配置及配套素材一起恢复；不要在应用运行期间替换目录或手工删除看似未使用的素材。当前没有开放素材清理入口。

## 诊断

诊断页提供最近 500 条事件、日志存储状态、主机传输统计和导出。操作结果与状态迁移记录匿名设备键、会话、操作号及原错误编号；整帧 USB 完成记录实际分片总字节和发送调用耗时，均不等同设备呈现。

遇到失败可保留错误编号并导出诊断。导出不包含图片、原始配置或个人完整路径；源码匹配信息不能替代实际固件／驱动兼容证据。设备联调、文件恢复和导出内容的运行验收仍未完成。
