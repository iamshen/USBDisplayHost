现有四生产工程和 Velopack 已锁定 SDK／依赖；见 `dependencies.md`。`build.ps1 -Action Package` 生成包含 .NET／WPF 运行时的未签名离线 Setup，使用方法见 `offline-installation.md`。入口在单实例与设备服务之前处理安装 hooks，并显式关闭启动自动应用更新；卸载只清理属于当前应用路径的自启项，保留独立数据和驱动。现有 IAppUpdateService 仍仅定义平台无关边界，尚无检查、下载或更新交接实现。

打包器生成的完整包和本地索引仅作为本地产物，不上传、不配置演示更新源。当前阶段不需要 HTTPS 源即可生成离线安装包。正式发布方仍需提供地址及证书公有验证信息，私钥、令牌和证书密码沿安全签名链路交接，不进入仓库。正式包必须先于索引发布，隔离验证索引不得写入正式源；来源、签名、架构与目标版本不完整时不得进行在线下载或更新安装交接。

离线打包已有静态核对和构建证据，尚未执行应用、安装／卸载或设备运行验收；打包显式跳过会启动主程序的入口探测。2.5、12.x、13.x 的签名、运行和正式发布父项保持未完成，独立实现及构建证据见 `../verification/offline-installer-2026-10-22.md`。
