# USB Display｜深色工作区 UI 设计方案

版本：设计规范 v1.3 · 更新日期 2026-10-14。本文描述当前页面规则与后续功能边界；实际 WPF 截图及未完成项见 [全页面重排记录](../../verification/all-pages-redesign-2026-10-13.md)。本目录静态 SVG／PNG 保留为设计资产，不代表当前运行布局。

## 1. 设计定位与参考依据

面向使用 USB 显示设备的 Windows 用户，以“选择设备 → 编辑内容 → 预览 → 应用 → 查询结果”为主流程。默认深色，窗口画布使用深炭灰，控件以深灰分层，亮蓝色仅用于当前选中与主要操作。

功能参考来自提供的六张截图：设备入口、电脑监测、系统规格、应用设置，以及两个主题选择／设备调节状态。截图内文字仅作为产品功能资料。视觉参考来自 [Watt Toolkit 官方仓库](https://github.com/BeyondDimension/SteamTools)及其 [Windows 网络加速截图](https://raw.githubusercontent.com/BeyondDimension/SteamTools/develop/res/screenshots/screenshot-windows-accelerator.webp)。本次实际查看了该截图，其标题显示 v3.0.0-preview3；不将它称为最新发行版界面。

当前采用原生设备工具布局：深炭灰画布、紧凑设置行、清晰的预览与操作区，避免把过程状态和技术字段堆成主界面。顶部与侧边导航可配置，颜色均为项目语义令牌，基础控件沿用 WPF UI。

正式规范见 [UI 设计规范](../../06_UI设计规范.md)，本目录提供页面设计稿与详细布局说明；设计资产不代表功能已实现。

| 4 应用设置 | 自启、单位、语言、更新、支持 | 应用设置分组列表 | 自启／关闭／模式策略已有；更新目标包含检查、下载、校验与安装全过程；语言、温标设置需新增模型与本地化／单位支持 |

| 6 主题管理 | 选中反馈、创建、编辑、更多动作 | 模板选择与图片选择；扩展主题库另行规划 | 图片导入不等于主题包导入；批量导出、动画、自定义编辑器无现成功能 |
| 5、6 电机／固件 | 外设能力控制与设备维护 | 当前版本不显示电机和固件升级入口 | 不存在确认的电机能力；OTA 属 REQ-16 后续范围，不能借 UI 引入命令 |

电脑监测和系统规格完整设计在本交付中给出，标记为“扩展设计”。产品上线时，只展示实际已接入的二级视图；开发状态不能以可点击的假功能呈现给用户。后续接入成功后无需重做一级导航。

## 3. 页面架构与全局骨架

设备、主题、设备设置、诊断、应用设置共用五个页面实例与唯一宿主。默认顶部导航，侧边布局宽 184 DIP，均采用图标加中文名称；小于 800 DIP 收为页面菜单。页面宽屏边距 32 DIP，紧凑边距 16 DIP。编辑页底栏占独立布局行，不覆盖滚动字段。

设备选择与连接分开。切页和切换导航布局保持会话与内存编辑，不自动发送命令。主题与设备设置不提供草稿文件管理；应用成功后自动保存对应设备恢复配置。设备参数随当前会话切换，主题已有编辑则保留，直到明确应用或撤销。

## 4. 视觉令牌与控件规范

当前语义资源见 [UI 设计规范](../../06_UI设计规范.md) 与 Desktop 的 SemanticResources、ThemeOverrides.Dark。画布 #14171B，面板 #1C2026，导航 #111419，抬升面 #282E37，主文字 #F3F5F7、次文字 #A7B3C2，主要操作 #149CFF 配深色文字 #001525。

字体沿用 Segoe UI 与 Microsoft YaHei UI。标题、分组、正文和辅助文字使用共享样式；正文统一前景，主按钮继承自身前景，避免黑字落在深色背景或亮按钮上的低对比文字。控件沿用 WPF UI 模板及原生命令、校验、焦点与选中语义。高对比度继续使用动态系统颜色，实际完整验收仍待完成。

## 5. 五页实现

| 页面 | 布局与操作 |
|---|---|
| 设备 | 页头检测、紧凑离线连接提示、可用设备列表；连接后预览与控制并列；连接详情折叠，错误和恢复动作独立展示 |
| 主题 | 三模板横排选择，左侧大预览、右侧约 320 DIP 内容设置；六个圆形色板配颜色输入；底栏恢复默认、撤销、应用到设备 |
| 设备设置 | 图像输出为主：方向示意＋四项角度选择，帧率与画质输入／滑块；独立即时亮度分组；底栏应用设置 |
| 诊断 | 传输状态、USB 已发送帧数、日志写入三项摘要；运行详情、工具栏和有限高度事件日志 |
| 应用设置 | 窗口与启动、设备模式、软件更新；紧凑设置行；顶部／侧边导航立即预览，撤销更改或保存设置 |

主题可离线编辑预览，应用必须满足连接、主题模式、亮屏、未暂停及会话门禁；设备设置字段在可应用时开放。应用期间暂停本页编辑，完成后自动保存，不增加额外保存步骤。保存失败显示持久结果并只重试本地保存。

模板、范围与默认值保持原业务规则：图片 PNG／JPEG、时钟及仪表盘；方向 0°／90°／180°／270°，帧率 1～5（默认 5），JPEG 画质 70～85（默认 80）。颜色和模板预览来自真实渲染，缺失指标不伪造零值。

软件更新尚未接入，检查入口禁用并显示原因。监测扩展、系统规格、语言／温标、通用主题库等保持后续设计边界，不显示假功能入口。

## 6. 关键状态与对话框

设计稿 `11-states` 为状态组件板，`12-compact` 为 640×400 紧凑原稿。

| 状态／弹窗 | 内容与动作 | 语义约束 |
|---|---|---|
| 设备未连接 | 重新检测、离线编辑 | 可编辑和预览，不可发送 |
| 连接中／切换中 | 当前阶段、取消等待 | 禁止重复发起，取消不等于硬件撤回 |
| 结果未知 | “操作结果尚未确认”＋核实状态 | 在核实前不重复写入，不显示成功勾 |
| 应用成功但保存失败 | “已应用，本地保存未完成”＋仅重试保存 | 不重复发送主题／亮度 |
| 素材失败 | 原因、重新选择／重试预览 | 保留现有有效输入，错误编号可复制 |
| 未应用内容退出 | 确认放弃更改或返回窗口 | 不隐式应用，不保存独立草稿；应用偏好与待保存恢复配置分别处理 |
| 首次副屏切主题确认 | “Windows 可能重新排列扩展屏上的窗口”＋切换／取消 | 可记忆不再提示；取消不发送命令 |
| 软件安装确认 | “将重启软件并短暂停止主题推流” | 仅更新管线接入后开放，主按钮重启并安装 |
| 退出资源未收敛 | “操作尚未结束，请稍候或查看诊断” | 不伪装退出完成，不释放未知归属资源 |

弹窗宽 440～520，窗口更小时左右各留 16；标题 20、正文 14、按钮 36；焦点先到安全的非破坏动作。Tab 限于弹窗，Esc 等于取消，关闭后返回触发控件。关闭不能隐式放弃未确认操作。

## 7. 紧凑窗口、键盘与可访问性

1000 DIP 及以上：按偏好显示顶部或 184 DIP 侧栏、主体双列；800～999：按偏好布局并将次要导航收入更多菜单，主体优先单列；低于 800：统一折叠菜单，页头显示中文标题。紧凑窗口预览限制高度，字段单列滚动，底部动作独立布局并按可用宽度换行。不能整体 Viewbox 缩小。

字体缩放增加时，设置行转上下结构，标签与错误可换行；200% DPI 下按可用 DIP 调整窗口，不改变设备帧的像素尺寸。导航项提供 AutomationProperties.Name，状态通过文字而不靠颜色；Slider 支持方向键，模板 ListBox 支持方向键／空格，按钮支持 Enter／Space。日志更新不抢焦点，采样不频繁触发读屏通知，仅状态变化播报。

首次进入页焦点在标题／首个主要可操作项；表单出错聚焦首个错误字段。小窗口的设备选择弹层不能遮挡唯一关闭入口。所有 Tooltip 信息也应能通过焦点或附近说明获得。

## 固件状态与关键流程画板

[设备状态与界面操作矩阵](../../contracts/ui-device-state-matrix.md) 定义现行 AD102 V2 下的全部门禁、默认值、恢复动作和需求追踪。页面、托盘与对话框共用该矩阵；它是本规范的组成部分。深色主题使用实色背景与面板。

SCREEN 下亮度、熄屏和唤醒禁用，保留原因说明；主题只编辑预览，应用禁用并显示原因。Off 时禁止切模式；THEME 提供显式唤醒，SCREEN 不提供无协议支持的唤醒捷径。首次 SCREEN→THEME 显示 Windows 可能重排窗口的确认，可选择不再提示。模式 PID／HID 已确认与 Windows 桌面输出可用分开呈现。

画板 15～23 对应多设备选择、连接、SCREEN、Off、暂停、切换、未知、恢复和失败；24～25 对应托盘与退出；26～31 对应软件检查、发现版本、下载校验、安装确认、失败恢复和新版本确认；32 对应缺失与过期指标。11 包含首次切出确认及未应用内容退出确认，05 自动检查默认开启。画板中的版本、数值与错误编号均为示例。

流程画板沿用 1180×820 画布、标题与状态卡、四阶段进度、常驻原因区及底部动作行。多设备选择使用单选列表，选择与连接分离；确认选择前主操作不可用。连接／切换／恢复使用不定进度，阶段由真实事件推进。未知结果的主操作为核实，恢复失败才按实际原因提供重新检测。取消等待后仍保持收敛门禁。托盘菜单使用原生命令项并同步禁用原因；退出对话框处理完未保存内容后再进入资源收敛，重试切换前先核实。

更新状态以独立状态模板呈现，不同时显示多个失败阶段的动作：检查失败→重新检查，下载或校验失败→重新下载，安装／启动失败→官方完整包和日志；更新源未配置时禁用检查并说明原因。下载未知总量及校验使用不定进度，只有真实字节数可计算百分比。待安装点击后弹 ContentDialog 确认，安全收敛期间禁止重复安装；新进程确认版本、配置和窗口／托盘初始化后才显示完成。

CPU、内存、PC 传感器和设备反馈分别标来源，缺失显示“不可用”；停更超过 3 秒保留最后值并标过期。固件温度／FPS 占位不能显示为真实零值；主机发送统计不能冒充设备实际 FPS。
