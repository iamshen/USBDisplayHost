# 设备页选择协调器交接代码基线

关联 REQ-01／FR-01、D1／D3、T-09，任务 4.2。仅有代码与目标 Release 编译证据。

App 为设备页注入原唯一 DeviceCoordinator、DeviceSessionLifetime 和错误报告器。ConfirmSelectionCommand 不再仅保存 UI 私有选择：先用当前发现版本取得实际 DeviceSelectionAdmission，再等待协调器 SelectAsync 受理；成功后保存完全相同的发现凭据和选择对象。此步骤只发布 Discovered 与会话代次，不创建原生设备对象、不初始化主题、不自动连接。

页面要求当前 Disconnected、无保留 owner、无忙碌会话且发现版本仍有效才受理确认，已有选择请求时不再受理确认或重新检测。Core 原有请求队列、发现凭据、旧所有者和状态门禁仍再次检查。完成时凭据过期或已经退出，将对应键／代次通知失效，不把陈旧凭据交给后续连接；核验普通异常带错误编号并撤销已受理选择，不崩溃或报告连接成功。

重新检测仅在原状态为 Discovered、无在途操作／保留 owner／忙碌会话时通知原选择失效，再走原实际重扫，不从 Ready／Opening 等状态隐式关闭设备或替换正在使用的资源。协调器状态和生命周期更新刷新确认动作。发现关闭先停止选择命令、请求取消并等待命令结算，再停止 presenter 和发现生命周期；不靠 UI 停止证明原生资源已关闭。

App 仍未创建真实发现或控制／parser 适配器，当前运行无法完成实际枚举／连接。设备切换的旧会话关闭和新资源打开、草稿按设备绑定、模式／电源与设备行为尚未完成。本入口不替代这些流程，也不把选择成功当作连接验收。
