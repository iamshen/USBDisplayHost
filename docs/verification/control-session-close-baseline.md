# 物理会话控制面关闭契约代码基线

关联 REQ-01、D3、T-10／T-17，任务 4.3／9.4。

IApplicationSessionState 新增必需 CloseAsync，返回明确的 OperationResult<Unit>，不提供成功默认实现。Drain 只确认当前观察请求／取消回调收敛；Close 必须进一步确认物理会话的控制句柄、读取循环、回调和相关资源全部释放。关闭不得通过切模式或电源命令代替资源释放，未知结果保留所有者并禁止用新实例替换。

该观察所有者按单一物理会话作用域创建，连接工作、应用工作和主题管线共享同一实例，不能跨物理会话共享。普通应用工作只 Drain，保留观察器供后续应用；失败连接在其他相关 I/O 全部收敛确认、数据传输关闭后才关闭观察所有者。成功连接保留观察器，仍须由实际组合根将其转交完整管线。

ThemeSessionPipeline 在生产者／操作／调度器／观察／帧／原生传输依次收敛且数据传输关闭确认后，等待控制面 Close。只有控制面也返回 Success，原生关闭任务才成功；之后才能处理本地引用和发布完整释放状态。Failure／Cancelled 均不能证明控制资源已关闭，转换为 Unknown；普通关闭异常沿用诊断及未知关闭处理，缓存关闭任务不重复执行已完成的部分释放。

真实 HID 状态观察／关闭适配器仍未实现，App 没有创建物理会话。当前只补齐必需接口及所有权收敛边界，没有替代协议契约、驱动或资源运行证据。
