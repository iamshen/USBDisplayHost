# 工作区短时提示代码基线

关联：T-29、任务 3.2，REQ-07／FR-07、REQ-10／FR-10。

MainWindow 在现有内容层附加锁定 WPF UI 4.3.0 的 SnackbarPresenter，使用同一个 SnackbarService 替换提示，显示 3 秒。API 与替换行为以本地锁定包的 Wpf.Ui.xml 为依据，目标 Release 编译验证了实际构造、图标、外观与 presenter 接口。

WorkspaceNoticeLifetime 仅订阅已有六条异步命令：设备暂停／恢复、断开、本地待保存处理、主题应用和设备设置应用。观察到命令运行且对应页面实际业务忙时才记录本次受理；结束后读取页面最终结果。同步拒绝、没有实际受理或异常终止不拿上一次结果生成新提示。提示不检查 USB、不重试业务、不自行判断保存／呈现成功，不改变编辑或请求。

提示只有一个最新结果与一个待处理 Dispatcher 通知，不保留历史队列；文本最多显示 200 字并以省略号结尾，完整结果和原错误编号仍在原页面常驻。失败使用警示外观；普通结果使用中性外观，不把任务正常结束画成设备已经呈现成功。隐藏／最小化窗口不显示或积压提示，不唤起窗口。托盘原有失败唤起仍由实际错误路径处理。

工作区停止先解除六条命令订阅并撤销尚未呈现的通知，再停止原电源／会话链。调度或呈现普通异常只写诊断，不传播到已经结束的设备／保存操作，不将短时提示作为唯一错误渠道。现有消息框交互不因本次提示改变。
