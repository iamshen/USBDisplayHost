# 设备页显式断开实施记录

关联：REQ-08／FR-08、REQ-09／FR-09、T-13／T-29，任务 3.2、5.1、9.4。日期：2026-10-08。

设备页提供“断开设备”命令，冻结当前 Desktop 会话所有者的设备键与代次，再调用 DeviceSessionLifetime.DisconnectAsync。没有实际接管的管线、正在选择／应用／构建／关闭、退出或未知关闭时不能受理。尚未连接的发现选择不冒充已经释放原生资源；当前 App 未组合真实管线，因此该按钮保持不可用。

显式断开复用管线已有关闭链：使原代次失效，停止产帧并等待在途应用，停止调度，确认控制与帧 I/O 收敛，再关闭传输和控制资源，最后交接本地配置引用。该入口不设置应用退出标志，不退出窗口，不发送熄屏或切模式命令，不放弃待保存配置。完整 Success 且可释放所有权才清除 Desktop 会话强引用。

关闭任务共享，未知结果保留整条管线且不重复原生操作。原生关闭已确认而本地交接明确失败时，按钮改为“完成本地交接”；再次请求仅复用已完成的原生关闭任务并处理本地引用。设备页不自动丢弃候选。所有异常及非成功结果保留常驻原因、动作与错误编号；页面停止等待已经受理的断开任务。

设备页展示当前实际 PendingSave 的目标设备、冻结修订、保存状态及原错误，提供“核实／保存恢复配置”。点击冻结实际 RetryId，复用既有本地重试：Unknown 只读取主文件精确核实，不重写；明确失败保存走原存储门内合并。未持有可信保存候选、会话操作忙、正在断开、未知原生关闭或页面停止时拒绝。该动作不发送帧、不改变草稿、不重新连接；成功后仍需显式完成本地交接，不能把保存成功当作整条会话已经释放。它直接读取原所有者记录，不依赖主题／设置页面是否展示过该结果。

实际本地处理结果单独常驻，带原目标与修订，页面 1Hz 的当前待保存信息刷新不覆盖失败提示。生命周期服务在本地处理任务结束后发布新的同阶段版本，让跨页门禁重新读取待保存结果；原关闭阶段和关闭错误保持原义。页面停止等待已受理的本地处理，没有额外重试循环或自动放弃动作。

仅执行目标 Release 构建和 `git diff --check`。未启动窗口、附加管线、操作设备、运行测试或进行视觉验收；实际断开、未知关闭、待保存交接和重连行为尚未验证，父任务保持未完成。
