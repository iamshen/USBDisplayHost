# 设备发现工作区代码基线

关联 REQ-01／FR-01、D1～D3、T-09，任务 3.2／3.3／4.2／9.4。

设备页新增实际发现列表、检测状态／错误、重新检测、选择设备及选择结果。列表以 VID＋序列号永久键分组，保留各接口 PID／容器／位置；不把 PID 当永久键。Core 解析器核实多接口关联，歧义行显示错误并禁止确认选择。未知身份拒绝整个页面投影，不静默删除失败项。完整成功且版本仍匹配才允许选择，不自动选首项，也不将选择当作连接成功。连接按钮保持不可用。

重扫快照撤销候选／已确认选择；确认动作重新要求生命周期当前列表版本。SelectedDevice getter 也重新核对当前版本／选择资格，避免隐藏窗口尚未呈现通知时向业务暴露旧选择。重扫只提交有界请求，不在命令中调用原生探测。

DeviceDiscoveryPresenter 消费一个最新快照槽，后台不等待 Dispatcher，最多一个待更新动作。隐藏窗口保留最新快照，恢复时读取当前状态。普通读取／呈现异常记录错误编号；停止时撤销待更新动作，取消且等待读取任务，不用界面读取停止代替原生关闭。

App 创建可选 DeviceDiscoveryLifetime，未附加 WindowsDeviceDiscovery 时不创建监视器、枚举或探测。UI 线程附加先创建带移除接续动作的生命周期，成功后转移所有权，门禁拒绝时调用方继续持有；进入附加后异常返回 Unknown，工作区保留发现生命周期。工作区先结束实际设备会话，再停止发现呈现及原生发现生命周期，确认后才释放协调器、渲染和日志等后续资源；未知关闭保留窗口与所有者。

尚未提供真实兼容记录并调用发现工厂／附加入口，实际列表为空、检测／选择不可用；未伪造设备。当前 Identity 路径的移除接续代码见 `device-removal-baseline.md`，完整多接口集合、正式连接及控制仍未接入。仅完成代码与 XAML 编译，未宣称运行行为或视觉验收完成。

仅运行目标 Release 构建，四个生产工程 0 警告、0 错误。未创建或执行测试、调用原生接口、打开设备、运行 WPF 窗口或截屏。实际视口、键盘／辅助技术、热拔插和多设备验收仍缺证据，3.2／3.3／4.2／9.4 父项保持未完成。
