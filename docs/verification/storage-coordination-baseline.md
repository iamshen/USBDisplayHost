# 配置与素材共同存储边界实施记录

关联：REQ-04／FR-04、REQ-08／FR-08、T-18、任务 7.1／7.2、TC-14／TC-26。日期：2026-10-08。

Windows StorageCoordinator 绑定一个明确的用户数据目录，持有同一 StorageBoundary 和进程内素材引用索引。FileProfileStore、FileAssetStore 要求传入该协调器并核对目录归属；不再各自创建独立锁或素材索引。App 只创建一个协调器，注入全部配置与素材存储；同一目录的其他存储实例也必须复用该实例。

恢复配置、主题／设备设置草稿、应用设置读写、引用扫描、素材导入和素材打开共用一个有界互斥入口。等待锁可以被用户令牌取消，已开始的操作仍遵循原原子提交与资源收敛契约。取得读取流后互斥入口释放，实际读取期间由租约和流所有权保留素材；不能把锁已释放解释为文件已经关闭。没有新增文件格式或改变设备协议。

导入完成完整解码、刷盘后，提交素材文件前取得 Importing 租约。成功 ImportedAsset 拥有该租约，调用方必须在取得自身引用后释放结果；没有被采用的成功结果也必须释放。主题编辑页在当前图片模板、未停止、未取消时先取得编辑引用再释放导入引用。模板变化／取消／退出后的迟到成功不会更新编辑，但也不会泄漏导入引用。明确失败前取得的导入引用由导入边界释放。

这关闭了“文件已提交、结果仍在等待 UI 采用”期间没有进程内引用的间隙。全部 IAssetStore 消费方当前为生产素材存储和主题编辑页；未创建测试实现。导入结果带租约不代表已保存草稿，也不代表用户采用它；取消后可能保留未引用的已提交素材，后续清理须另行核实。

同一协调器只提供本进程共同存储边界，不协调外部程序或使用另一协调器的代码。无引用清理仍须将配置扫描、素材租约与删除预约组合成一个事务，拒绝未知格式及未核实引用来源；当前未增加删除入口，也未执行文件删除。导入期间配置操作会等待同一边界，实际延迟未测量。

Core 素材索引已提供 ReserveUnreferenced：规范化素材标识，在租约取得的同一锁内确认零进程内引用并取得唯一清理预约。存在编辑／渲染／候选／活动／待保存／导入引用时拒绝预约；预约期间同素材的新租约立即返回失败，其他素材仍可取得引用。全局最多一个预约，没有额外排队；预约 Dispose 幂等，只有所属预约释放后才开放该素材的租约取得，不用“先查数量、再独立删除”的非原子判断。

预约仅证明进程内引用互斥，不证明没有恢复／草稿／备份或未核实文件引用；没有磁盘路径、文件打开或删除行为。尚未由 Windows 清理事务调用，调用方未来必须在已持有共同存储边界、磁盘引用完整核实且文件范围核实的情况下使用，并在实际操作完成后释放预约；不能用其代替未知文件／写入收敛。预约与租约的并发行为仍无运行证据。

FileProfileStore 读取已知图片恢复配置或主题草稿时，在共同存储边界释放前取得 ConfigurationRead 租约，并随成功读取结果交给调用方。取得引用失败不返回一个可以继续使用但未保留素材的成功配置。无素材主题、缺失／未知高版本没有已解码素材时不取得租约。

ProfileReadResult／DraftReadResult 为拥有租约的 IDisposable 结果。应用事务、仅本地保存重试、草稿初始化和未知保存核实四条当前调用链已在全部结果分支用作用域释放；界面／候选取得自身引用后才结束读取结果作用域。读取结果在等待调用方接收期间仍保护原素材，不依赖当前磁盘文件稍后是否被替换。重复释放结果不重复扣减租约。此 API 所有后续消费者也必须遵守读取结果所有权，不能只提取字段后丢弃拥有租约的结果。
