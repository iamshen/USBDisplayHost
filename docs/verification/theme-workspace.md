# 离线主题工作区实施状态

日期：2026-10-08。关联 OpenSpec 3.3、6.6、7.6、9.3。记录生产代码与目标构建结果，不作为真实窗口或设备验收。

## 当前实现

Desktop 组合配置存储、受限素材导入、STA 渲染器和草稿预览。主题页提供图片／时钟／仪表盘字段、图片选择与取消、色彩校验、16:9 预览和显式保存。页面宽度不足 850 DIP 时改为上下布局。

离线草稿使用独立存储路径，不冒充设备配置。读取失败、备份恢复及高版本只读状态呈现于页面。保存冻结当前修订，保存期间的新编辑仍保持未保存；素材导入只替换素材字段，不覆盖期间的其他编辑，切换模板取消旧导入。

预览保留一个最新请求、一次在途渲染／解码及一个最新 Dispatcher 呈现。设备键和修订共同过滤迟到结果；隐藏页面、最小化或隐藏窗口停止预览请求并取消在途工作。时钟／仪表盘按 1Hz 请求，错误保持可见并提供显式重试，不无限重试相同失败修订。仪表盘读取后台主机 CPU／内存快照，无输入的温度项显示不可用，采样实施范围见 `telemetry-baseline.md`。

普通关闭默认收至托盘并暂停预览；显式退出执行草稿保存／放弃／取消决策，再停止文件操作、预览循环、STA 渲染器和指标；繁忙操作提示等待或取消。系统注销／关机路径不弹草稿对话框，启动尽力清理。没有 POWERDOWN 命令实现或调用。托盘范围见 `lifecycle-baseline.md`。

## 验证与边界

只执行目标 Release 构建及差异空白检查；未启动应用、创建或执行测试、连接设备。布局、图片内容、键盘、DPI、辅助技术及关闭竞态尚无运行证据。

设备草稿切换、活动／历史预览、设备应用事务、温度指标、设备托盘动作和系统退出有界资源回收仍待实现。应用设置退出决策已接入，详见 `application-settings-baseline.md`。单实例、托盘与退出代码尚无运行证据，不能关闭 9.1／9.2／9.3／9.4。系统退出的异步清理不保证 OS 结束进程前全部完成。
