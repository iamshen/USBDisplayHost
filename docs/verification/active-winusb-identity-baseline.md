# 活动 WinUSB 身份复用代码基线

关联 REQ-01／FR-01、D2、T-09，任务 4.2／4.3。

共用路径所有者内部持有可撤回的已核实身份，包含接口 GUID、实际设备修订和 DeviceIdentity。只有正式打开链确认实际 USB 描述符／序列号、接口／端点及策略回读，并重新读取当前 PnP 容器／位置与选择一致后才发布。探测所有者和未知释放所有者不发布可复用身份。已占用但没有可复用身份的路径仍拒绝重新初始化。

WinUSB 身份探测优先读取相同路径／GUID 的活动身份，核对本探测器的显式 VID/PID／修订兼容记录，再读取当前 PnP 归属，最后确认仍是同一未撤回的所有者记录。此分支不调用 CreateFile、WinUsb_Initialize、USB 描述符读取或策略设置，不重新初始化活动接口。PnP 归属改变立即撤回旧身份；访问失败、取消和未知释放不返回成功身份，不静默跳过设备。

正式会话开始关闭即撤回身份，先于原生收敛／释放；I/O 错误、完成未知或普通 I/O 异常也撤回。未知关闭保留路径占用但不能复用身份。身份记录用于发现，不能证明连接 Ready、设备模式、电源、能力或固件协议状态。复用结果是核验时的身份快照，WindowsDeviceDiscovery 仍负责通知代次过滤；没有以进程内预约替代外部进程互斥或热拔插行为证据。

仅运行目标 Release 构建，四个生产工程 0 警告、0 错误。未运行测试、原生调用或窗口。App 发现／选择／连接组合、真实兼容记录、重插同路径、多接口归属、驱动和设备行为证据仍未完成；4.2／4.3 父项保持未完成。
