# 连接到管线的所有权交接代码基线

关联 REQ-01、D3、T-09／T-10／T-17，任务 4.2／4.3／9.4。

协调器在实际受理主题 Connect／Recover 工作时持有唯一 ThemeConnectionSessionWork。连接成功后保留工作及其传输、控制观察器和 parser，直到完整管线明确接管；原连接仍待交接或关闭时，不受理新的设备请求覆盖它。没有以 Ready 发布或操作返回成功丢弃连接资源。

TransferConnectionTo 在协调器锁内要求当前 Ready、设备键／代次匹配、无在途工作或失效、未关闭且存在待接管工作。工作重新核对发现凭据和成功收敛结果，严格要求管线使用同一协调器、传输、控制观察器、parser 和能力对象。交接异常返回带错误编号的 Failure，保留原连接。成功只转交一次，协调器以唯一 transferredPipeline 槽强引用已接管管线；Desktop DeviceSessionLifetime.Attach 同时持有自己的会话所有者，门禁拒绝不会替换原所有者。

断开快照或代次失效不等于资源已释放。已接管管线仍存在时，Core 拒绝新的选择、Connect 及替代 ThemeConnectionSessionWork，包括新恢复连接；当前会话的正常应用和控制不被此门禁拒绝。只有该管线原生关闭和本地配置引用交接均成功，才通过内部 ReleaseTransferredPipeline 核对对象引用并清除槽。未知原生结果或未处理本地保存结果持续保留它；拒绝外部其他管线清除该所有者。选择受理、转交和释放共用协调器锁，不读取管线的加锁属性，避免引入协调器到管线的锁反向等待。

协调器 DisposeAsync 在已接管管线尚存时明确拒绝关闭，不提前停止单写者或声称整体释放；应用关闭链须先完成设备管线关闭和本地交接，再停止协调器。

未接管连接在失效、失败或退出时执行缓存的 CloseUnattachedAsync，等待实际执行结束、工作 drain 及数据／控制资源关闭。成功已交给管线的工作拒绝自行重复释放。调度阶段尚未调用 Execute 时发生普通异常，协调器明确记录未执行，再走同样的观察／资源关闭链，不通过取消凭空证明资源不存在。

后台关闭仅传回一个关闭结果，协调器单写者处理结果并清除确认关闭的连接；未知关闭保留完整工作，标记原生所有者未确认并阻止替代会话。退出等待未接管关闭结果，不能提前结束协调器或报告整体释放成功。关闭和交接互斥，原始连接错误及关闭错误仍分别可追溯。

实际管线创建器已实现，详见 `theme-pipeline-build-baseline.md`；HID 观察／parser 适配器、真实兼容契约及 App 连接入口仍未接入。该交接基线不代表真实连接图已经运行，没有运行资源生命周期或真实设备验收。
