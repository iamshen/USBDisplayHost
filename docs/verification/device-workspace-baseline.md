# 设备工作区快照接入基线

关联 D3／D7、REQ-01／FR-01、任务 3.2／3.3／5.1。当前为生产快照投影代码与编译证据，未完成 TC-29／TC-30／TC-31／TC-32 的窗口或设备验收。

## 当前实现

App 组合根创建一个 DeviceCoordinator，与工作区、快照呈现器及 DeviceSessionLifetime 共用。会话接管先核对管线使用同一协调器，不接受另一个协调器的会话，不能出现页面显示与实际所有者各自维护状态。实际管线构造和设备连接尚未接入。

设备页使用缓存的单个 ViewModel，展示协调器快照里的设备身份、已核实分辨率、固件、请求亮度、读回亮度和在途操作。没有描述符或读回证据的字段显示“尚未核实／尚未读回”，声明但未验证的固件附未核实状态，不使用设计中的 VID/PID 或默认亮度冒充实际值。

可复用 DeviceStatus 控件独立展示连接、模式、电源、推流四个维度；错误与订阅故障用常驻 InlineMessage 单独展示。未知枚举不显示成已就绪或已停止。未提供虚假发现设备、连接成功、模拟活动预览或设备已显示反馈；页面明确显示发现与连接尚未接入。

DeviceSnapshotPresenter 订阅协调器容量 1 的最新快照槽，后台持续读取，不等待 Dispatcher 或页面消费。只保留一个最新快照、一个待处理 Dispatcher 通知；窗口隐藏／最小化后不投递新通知，恢复时读取协调器当前版本。ViewModel 按单调 Version 拒绝旧值，订阅意外结束或普通异常保留诊断编号及可见错误，不能把最后一次就绪快照当作更新仍正常的证明。

该订阅由应用工作区持有，切页不创建新订阅或会话；当前不是每页独立生命周期订阅。普通关闭先确认物理管线收敛，再停止页面命令、取消呈现订阅并等待读取任务，然后关闭协调器，随后释放预览／渲染／采样／诊断。停止会中止尚未执行的通知，通知回调检查停止状态，不等待 UI 来收敛设备写入。
