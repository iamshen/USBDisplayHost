# 会话关闭结果呈现代码基线

关联 REQ-01、D3、T-17，任务 3.2／9.4。

DeviceSessionLifetime 发布独立单调版本的 SessionLifecycleSnapshot，包含固定设备键／代次、关闭阶段、原生关闭确认和业务错误。接管、开始原生收敛、本地结果处理、完整释放、保留本地结果及未知关闭分别呈现，不用协调器 Disconnected 代替所有资源已释放。关闭任务在执行时也计入 IsBusy。

管线 IsNativeClosed 只在缓存的原生关闭任务成功后为 true，不以任务创建、取消、断开快照或本地保存结果推断。只有关闭成功且 CanReleaseOwnership 为 true，应用所有者才发布 Released 并清除管线。原生关闭确认后本地引用／保存结果仍未处理的已知失败显示独立阶段；未知结果保留错误编号和恢复动作。

生命周期状态使用一个最新槽，不等待 UI。DeviceSnapshotPresenter 独立消费协调器和生命周期槽，合并到同一个待 Dispatcher 更新动作；隐藏时只保留最新状态，恢复时读取当前状态。设备页按生命周期版本过滤旧更新，独立显示关闭状态与常驻错误。停止时等待两条读取任务，诊断继续最后停止。

没有新增设备重连、原生释放重试或业务写入按钮，不以页面呈现替代生命周期收敛。版本耗尽不回绕、拒绝接管新管线，仍允许既有资源关闭。实际管线还未在 App 创建或接管，默认页不会显示模拟关闭结果。

仅运行目标 Release 构建，四个生产工程 0 警告、0 错误。未创建或执行测试，未运行关闭、原生调用、WPF 窗口或截图；实际关闭结果／错误、目标视口和辅助技术证据未完成，3.2／9.4 父项保持未完成。
