# 主题模式连接工作代码基线

关联 REQ-01／FR-01、D2／D3、T-09／T-10，任务 4.2／4.3。

Core ThemeConnectionSessionWork 组合明确选择凭据、数据接口、固定会话代次、电源意图、控制状态观察器、传输、parser 恢复和主题初始化器。初始化器必须使用同一传输，所有入口保持 Core 无 WPF／原生句柄。工作单次执行，只在协调器实际 Opening／Recovering 上下文和有效发现凭据下继续。

先读取并收敛实际控制观察。真实主题模式、驱动核验、固件／能力字段、选定身份和电源必须匹配；副屏或不明状态在打开数据面前拒绝，不占用厂商副屏数据面。亮屏意图还要求实际亮度，未读回时拒绝，不填充默认设备事实。

打开后核对真实传输限额，亮屏分支恢复 parser 并确认收敛，带当前上下文清理凭据执行已有 EP0／AF 初始化，再确认初始化收敛并重新读取实际控制状态。所有阶段继续核对操作和发现上下文，最后实际状态匹配才返回观察结果；协调器仍须等待完整 Drain 再验证／发布 Ready，不以打开收据或初始化收据替代控制读回。

Off 分支跳过 parser 恢复和 AF 亮屏序列，已有初始化器按冻结契约决定是否进行安全 EP0 探测；未使用的亮度参数不表示默认亮度或设备读回。实际电源与保存意图不一致时拒绝，不擅自发送电源命令。

Drain 等待工作结束，依序确认观察、已执行的 parser、初始化和原生传输收敛。失败连接仅在全部原生收敛确认后释放传输并确认控制观察所有者 Close，成功连接保留它们供后续实际管线持有。Unknown 停止后续释放并保留工作及依赖，不重用工作或重放初始化。控制观察器仅在该物理会话内部共享，关闭契约见 `control-session-close-baseline.md`；parser 的共享依赖由同一物理会话组合根持有。

真实控制观察器、parser 恢复适配器及匹配固件契约仍未交付／实现，App 没有创建本工作，也没有模拟观察。副屏连接、保存意图恢复、成功连接到完整主题管线的所有权转移和实际设备行为仍未完成；该文件不代表正式连接已可用。
