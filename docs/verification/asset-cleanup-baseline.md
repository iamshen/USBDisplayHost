# 素材清理代码基线

关联 T-18、任务 7.2。此记录是代码与目标编译证据，不是 TC-14／TC-26 或磁盘行为验收。

## 当前实现

Core 的 `IAssetCleanupStore` 返回批次状态、已确认删除的素材标识、实际跳过保留的文件数与错误编号。取消或失败可以发生在部分完成之后；保留数量不表示未访问文件数量，失败结果不能理解为整个批次没有修改磁盘。

Windows `FileAssetStore.Cleanup` 在配置、素材共享的 `StorageBoundary` 内完成配置引用扫描、素材目录完整预检、逐项零引用预约与删除。配置主文件、备份或目录来源未核实时不开始删除；素材目录最多 4096 个普通文件，仅接受 32 位小写十六进制标识加 `.image`，不递归处理目录，不删除临时文件、未知条目或重解析项。

配置引用存在的素材直接保留；进程内编辑、渲染、活动、待保存、导入或读取租约存在的素材也保留。预约与新租约共用互斥锁，预约在本项删除及确认结束后释放。没有把零引用计数查询当成删除许可。

删除使用独占文件句柄，以读取属性与 DELETE 权限打开、不跟随最后一段重解析项。句柄属性及标准化最终路径核对后，对同一句柄设置删除标记；关闭后查询路径，仅“文件／路径不存在”确认删除成功。进入设置删除标记之后的异常统一保守标为 Unknown，停止后续素材处理，已确认清单保持有效，不自动重放。文件原生错误只进入诊断，返回业务原因、操作建议和错误编号。

接口依据微软文档：[SetFileInformationByHandle](https://learn.microsoft.com/en-us/windows/win32/api/fileapi/nf-fileapi-setfileinformationbyhandle)、[FILE_DISPOSITION_INFO](https://learn.microsoft.com/en-us/windows/win32/api/winbase/ns-winbase-file_disposition_info)、[GetFinalPathNameByHandleW](https://learn.microsoft.com/en-us/windows/win32/api/fileapi/nf-fileapi-getfinalpathnamebyhandlew)。`DeleteFile` 是单字节 BOOLEAN，使用 1 字节结构，不能按四字节 BOOL 声明。

## 尚未覆盖

清理入口尚未由 Desktop 界面或后台调度调用。没有运行该方法、创建清理演示文件或删除用户素材。

共享边界只协调复用同一 `StorageCoordinator` 的本进程存储对象。它不锁住外部程序、第二个不受约束的存储实例或人工修改配置；磁盘引用扫描也不是外部写入隔离事务。必须解决启用入口所需的目录所有权／外部写入协调后再接入产品流程，不能把当前代码描述为满足任意并发写入的安全自动清理。

未知删除会在释放共同存储边界之前记录 `PendingCleanupRecovery`，后续排队清理返回原错误编号与 Unknown，不再扫描或请求删除。`VerifyUnknownCleanupAsync` 在同一边界内只查询路径：明确文件／路径不存在才解除暂停；仍存在、拒绝访问或查询异常继续保留 Unknown。核实方法不删除文件、不清空已确认批次清单，也不以“文件仍存在”授权重试删除。没有执行此接口。

删除前在数据目录创建 `asset-cleanup.pending.json`，保存 schema 1、素材标识及关联编号。以 CreateNew 创建，不覆盖遗留记录，WriteThrough 写入并完成磁盘刷新后才调用素材删除。只有素材确认不存在并且记录删除确认完成后才解除暂停。清理调用或核实调用先读取遗留记录；非普通文件、超过 2 KiB、损坏、未知版本或无效字段均阻止操作，不恢复重放素材删除。清理记录存在也会阻止通用配置引用扫描推断素材可清理。

素材已确认删除但记录未清除时，该素材仍计入已确认清单，同时批次为 Unknown。核实接口只查询素材，随后删除已完成意图记录，不再次删除素材；因此该接口包含清理日志收敛写入，并非完全只读文件系统接口。核实清理意图时同时比对内存与磁盘素材标识、关联编号，防止清除另一笔记录。普通异常诊断通过 OperationId 关联该持久编号。

意图在创建或刷新阶段失败也保守暂停，部分记录不能自动清空。此策略提供代码层的重启恢复入口，尚未运行重启、损坏记录或断电恢复验证；文件刷新不等同于证明所有存储硬件断电持久性。没有排除外部目录替换造成的路径核实歧义，启用产品入口前仍须实现目录所有权与明确人工恢复流程。跨会话待保存结果展示，以及获授权后验证文件占用、目录变更、部分删除取消和真实恢复行为也未完成。现有父任务与 TC 验收保持未完成。

配置与草稿保存也在共同边界内先核实图片素材为普通文件且大小在导入上限内，持有 FileShare.Read 句柄直至配置写入收敛。图片缺失、重解析项或无效大小时返回 `ConfigurationAssetUnavailable`，不开始替换配置。该保护关闭本进程清理先完成、随后存入失效图片标识的路径；不重新执行完整像素解码，也不能代替外部目录所有权协调。
