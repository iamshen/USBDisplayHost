# 活动接口集合与断开收敛代码基线

关联 REQ-01／FR-01、D2／D3、T-09，任务 4.2／4.3／9.4。

Core DeviceSnapshot 新增不可变 SelectedInterfaces，由协调器受理明确 DeviceSelection 时写入。全部接口沿用已经核实的永久设备键与会话代次；不引入 WPF 类型或原生句柄。普通快照变更保留集合，断开失效清空集合。

NotifyInterfaceRemoved 在协调器锁内同时核对设备键、会话代次、活动状态和完整选定接口集合，路径忽略大小写匹配。其他设备路径或旧代次请求不能登记失效，无法归属的移除信号则保守停止当前会话。失效登记立即阻止 Core 存活检查，状态发布／取消操作仍由单写者执行。管线关闭随后提交无原因的断开通知时，不覆盖已经登记的移除业务错误。

工作区在登记移除失效成功后请求 DeviceSessionLifetime.CloseDisconnectedAsync，按管线公开的设备键／代次核对所有者。通知线程不等待关闭；应用所有者持有关闭任务，内部捕获普通异常并转换为 Unknown。重复通知不重放关闭。完整关闭沿用 ThemeSessionPipeline 的生产者、在途操作、调度器、状态观察、帧执行器和原生传输顺序，并保留待保存结果及其引用。

物理断开不设置应用退出门禁；确认关闭且引用处理完成后可以接管新管线。已确认原生关闭但仍有本地保存待处理时保留旧所有者，已知本地失败可经既有退出流程继续处理；未知关闭保持完整所有者，不能覆盖。接管新管线时清除旧的已完成关闭任务，避免下一次退出误用上一会话的关闭结果。

原生移除通知仍是消费时按当前上下文匹配，快速重插同路径的连接受理与通知代次门禁、模式切换后的新接口集合受理、自动关闭结果的专门页面展示、正式连接组合和实际设备验收仍未完成。不能把断开快照或关闭任务创建当作原生资源已经释放。
