# 应用设置与自启实施状态

日期：2026-10-08。关联 REQ-07／FR-07、T-17、TC-13／TC-33，OpenSpec 9.2～9.3。

## 页面与已保存状态

应用设置页提供关闭窗口行为、开机自启、模式意图、自动检查更新、当前版本与显式保存／取消保存／重新读取。默认收至托盘、自启关闭、自动模式意图关闭、自动检查更新开启。更新服务尚未接入，检查更新禁用，保存该选项不冒充已安排检查。

输入与已保存设置独立；切页共用一个 ViewModel，保存冻结该次字段，期间新编辑保留。关闭使用已保存的 CloseToTray，不使用未保存输入。重新读取刷新已保存基线，已有编辑不被覆盖；未知高版本禁止覆盖。设置加载在启动时开始，但只读取，不因保存意图自动写注册表或发模式命令。

当前没有已验证的模式控制服务，不能新启用启动切主题／退出切副屏；已有文件中的意图可查看和撤销，但不执行设备命令。Core 再校验新启用请求，不只依赖控件禁用状态。

## 串行保存与自启

Core ApplicationSettingsService 共用一个串行门，用户设置只修改负责字段；托盘提示只通过 MarkTrayNoticeAsync 更新 HasSeenTrayNotice，并合并最新持久状态，不用先前页面快照覆盖其他设置。Core 不依赖注册表、WPF 或句柄。

WindowsStartupRegistration 在后台访问当前用户的 Run 项，值名 USBDisplayHost，不改机器级注册表、不要求提权。保存开启时写当前 apphost 的带引号路径，关闭时只移除本应用匹配项；同名外部／旧路径项拒绝覆盖或删除。读回确认并记录可恢复的私有检查点。当前只接受 `UsbDisplayHost.Desktop.exe`，直接由 dotnet 宿主启动不注册宿主程序。

Run 命令限制为 260 字符，拒绝过长命令而不截断；参见 [Run／RunOnce 官方说明](https://learn.microsoft.com/en-us/windows/win32/setupapi/run-and-runonce-registry-keys)。Windows 不保证登录后立即运行；任务管理器禁用、组策略和实际登录行为未核验。后续安装更新须提供稳定启动入口及迁移策略，当前开发目录路径不代表 Velopack 版本更新兼容。

保存先改变并读回自启，再提交配置；配置返回明确失败或明确 Cancelled 时，使用检查点尝试恢复原注册值。恢复前核对当前值仍属于本次改变，不覆盖明显的外部变化。恢复失败显示待确认，而不是宣称回滚。提交直接抛出取消异常时不能推断未提交，按 Unknown 保留。文件结果未知时只核实主文件完整候选以及实际自启状态；两者匹配才确认成功，否则保留待确认，不因读到旧值自动恢复注册表。读取与写入不是跨进程事务，不承诺跨会话或外部注册表修改的原子性。

Core 持有带确认标识、完整冻结候选及错误编号的 PendingSave。自启改变直接抛出普通异常、返回 Unknown，文件提交未知或注册恢复未确认，均在释放串行门前保留该记录，阻止后续设置保存和托盘标记写入。托盘标记提交自身未知也受同一保护。待确认期间普通加载不更新服务的已确认 Current。

页面分别展示文件保存与实际注册状态；保存未知时禁用再次保存，“重新读取”转为核实待确认记录，也提供“核实保存”按钮。核实只读主文件与实际自启，不写文件或注册表；主文件全部字段（包括 HasSeenTrayNotice）匹配且自启状态属于当前应用、启用值一致时才确认。备份、不匹配、缺失、查询失败或取消均不能解除保护。确认只更新冻结保存基线，期间新编辑仍保留。明确放弃必须匹配确认标识，只移除进程内记录，不回滚实际设置；再次保存之前要求正常重新读取。初始化查询失败不导致进程关闭。未经保存，控件编辑不写系统启动项。

## 格式与退出

ApplicationSettings 新增 CloseToTray，旧文件缺少该字段时默认 true。版本化文件新写 schemaVersion=2，可读取 1／2；旧版本 1 程序将版本 2 识别为高版本并拒绝覆盖。读取不自动迁移文件，显式提交才写版本 2，沿用同目录临时／原子替换／备份；这不构成 12.6 的完整更新迁移验收。

显式退出先处理未保存应用设置的保存／放弃／取消，再独立处理主题草稿。取消不会先释放工作区；放弃决定不提前修改编辑，若后续草稿提示取消退出，设置输入仍保留。保存失败、待确认或期间出现新编辑均保留窗口。系统退出不弹这些确认，仍走尽力清理；真实设备停流和有界系统退出尚未接入。
