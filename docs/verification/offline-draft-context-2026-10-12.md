# 分设备草稿与设备诊断接入

日期：2026-10-12。关联 FR-04、FR-06、FR-08、FR-10，T-16、T-18、T-19、T-30；对应 OpenSpec 7.1、7.6、8.3。本文记录生产实现及编译，父项的窗口、文件和设备验收保持未完成。

## 分设备草稿

主题页和设备设置页新增当前草稿归属、读取所选设备草稿和读取无设备草稿。保存使用页面持有的设备键，不再固定写 `offline.json`。默认先读取无设备草稿；设备选择不自动迁移编辑或写入恢复配置。离线草稿仍可显式应用到所选设备，其他设备草稿则在命令受理前拒绝应用。

切换读取只在原编辑已保存且无未知保存结果时受理；异步读取冻结目标键与原修订。新编辑、停止或目标设备改变时丢弃读取结果，成功读取中的素材租约仍按作用域释放。未知高版本不采用默认值替代目标草稿，原编辑保持可见。

主题切换先取得新素材引用，再释放旧编辑引用；跨归属读取会清空其他模板遗留的隐藏字段与旧预览。页面修订维持递增，避免重读旧磁盘修订导致同会话应用退回旧修订，旧预览也不能覆盖新上下文。待保存结果和应用结果继续携带原设备与候选标识，切换不会把它们重新归属。

连接后保留独立“保存草稿”入口；读取与保存均不调用设备协议。工作区退出取消并等待新增读取命令。使用与恢复说明见 [当前配置与恢复说明](../07_配置与自动恢复.md)。

## 诊断关联

`IDiagnosticService.Write` 支持沿用业务结果的错误编号；Windows 适配器仅接受 N 格式 GUID，日志与内存事件使用同一编号，既有导出白名单继续过滤。不会写入业务错误原文、序列号或文件路径。

协调器记录非轮询操作开始、最终回执和设备四维状态变化。最终回执在资源收敛及观察核验后记录，底层成功不提前标为整个用例成功。正常 1Hz 查询不逐次记录开始／成功，不变状态不重复记录；查询失败和真实状态变化保留。关联包含匿名设备键、会话、操作号、单调耗时和已有固件基线，未补造驱动版本。

帧发送器记录完整 USB 帧的实际分片总字节与发送调用耗时；不完整写入使用返回给恢复路径的同一错误编号，只有完成已知且长度有效才记录包含部分片的实际字节，完成未知时不推算。帧异常同时记录原帧操作上下文。发送耗时包含该次发送入口的检查与写入，不是内容生成至 USB 完成或屏幕呈现时延，也不是性能验收结果。
