# 素材进程内引用实施记录

关联：REQ-04／FR-04、REQ-08／FR-08、T-18、任务 7.2、TC-14／TC-26。日期：2026-10-08。

Core AssetReferenceRegistry 提供素材租约；仅接受 32 位十六进制素材标识和已知引用用途，统一小写索引。同一索引最多 4096 个租约，额外请求返回带编号的失败；计数加减在同一锁内执行，最后租约释放时移除索引。AssetReferenceLease 的 Dispose 幂等，重复释放不重复扣减。用途包括 Rendering、Candidate、ActiveProfile、PendingRestore 和 DraftEditor，计数不包含路径或原生句柄。

IAssetStore 已提供 AcquireReference；FileAssetStore 的同一实例持有共享引用索引。OpenReadAsync 在打开素材前取得读取租约，打开失败释放租约；成功返回只读 AssetReadStream。同步／异步关闭先关闭实际文件流，再释放租约；关闭异常不释放引用，读取与渲染错误仍交由既有操作边界反馈。读取方须在全部读操作结束后关闭流，不支持调用方一边读取一边并发释放所有权。

当前 WPF 渲染已通过既有 OpenReadAsync 路径使用读取租约。主题／设置应用服务新增同一 IAssetStore 依赖，图片候选在渲染与发送前分别取得 Candidate／ActiveProfile／PendingRestore 三个租约；任一引用失败不发送，已取得的临时租约在操作结束时释放。无素材的纯色／时钟／仪表盘不取得租约。

USB 与活动提交成功后将预留活动租约转交服务，再释放旧活动租约；新活动是无素材主题时也释放旧引用。首帧失败或迟到提交被拒绝保留原活动引用。待保存候选获得独立租约；新的成功活动提交替换它时释放旧待保存引用。明确保存成功或 Unknown 重试核实主文件精确匹配候选时才释放待保存租约；失败／未知／取消／高版本／较新恢复文件拒绝重试均保留它。应用服务与渲染器必须使用同一个素材存储实例。

Desktop 草稿编辑已持有 DraftEditor 租约：新图导入或读取图片草稿先取得新引用，再替换原编辑引用；失败保留原编辑值。切换时钟／仪表盘仍保留页面记住的图片，切回图片不会丢素材。草稿保存对冻结图片另取 Candidate 租约，等待保存调用完成后释放，不因期间继续编辑而提前失去在途引用。页面停止等待初始化／导入／保存任务后释放编辑引用。

草稿预览的最新待处理图片及实际渲染分别持有租约，原请求被替换／失效时只释放待处理引用，已开始渲染的引用保留至渲染和 JPEG 预览解码结束。隐藏页面保留最新草稿引用；预览控制器停止等待工作后释放它。App 为编辑、预览与渲染注入同一素材存储实例。引用错误显示原操作错误编号，不继续保存或预览未取得引用的候选。

会话管线确认实际传输关闭后释放活动租约并禁止后续发送。待保存候选仍存在时保留待保存租约与服务所有者，返回独立的本地保存未处理失败；此时可仅重试本地保存。明确保存／核实提交成功后释放待保存引用；退出时明确放弃指定 RetryId 才可丢弃候选和引用，不能用旧候选的授权放弃较新的候选。此路径不撤销设备画面或已经发生的文件写入。原生收敛未知不进入引用释放阶段。

主题草稿 Unknown 保存保留冻结候选租约，提供只读主文件精确核实；成功核实或明确放弃本次确认后才释放，详见 `theme-draft-save-baseline.md`。普通停止不自动丢弃未知候选。备份匹配不能确认主文件提交，后续编辑不改变被冻结引用。

旧恢复文件／备份引用的完整扫描、热拔插后跨会话的待保存结果展示及磁盘清理尚未接入；引用交接尚无运行证据，不能声称资源全程有界已验收。索引是进程内保护，不是磁盘持久化引用索引；零租约不授权删除文件。恢复配置、草稿、备份、高版本未知配置、待保存及在途配置引用必须核实后才能实现无引用清理。未新增或执行素材删除操作。
