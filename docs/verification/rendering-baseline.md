# 离屏渲染实施与验证状态

日期：2026-10-08。关联 T-06、T-14，OpenSpec 4.4、6.1～6.3。本记录包含生产实现的编译证据，不是 JPEG／样机实验报告。

## 生产实现

`Rendering/WpfFrameRenderer` 实现 Core 的 IFrameRenderer；只向 Core 依赖。专用 STA 工作线程使用 DrawingVisual、96 DPI 的 RenderTargetBitmap 和 JpegBitmapEncoder，没有管理窗口 Visual 树或截图输入。

渲染器一个执行中请求，活动／草稿各一个可替换待处理请求；活动优先。被替换待处理请求返回取消，原执行中的请求保留资源至结束。退出取消在途请求并等待工作线程结束，未完成解码时不提前关闭输入流。已接入离线主题工作区退出清理，完整应用生命周期和实际退出验证尚未完成。

0／180° 使用 W×H 逻辑画布，90／270° 使用 H×W；最终输出固定请求的物理 W×H。图片适配依据 PixelWidth／PixelHeight，忽略图片 DPI 对物理宽高比的影响。PNG 透明区域由背景合成；JPEG EXIF 的旋转和镜像通过元数据查询实现，PNG 方向元数据的实际支持仍需核验。

白名单模板包含图片、时钟、仪表盘。默认图片是内置色条背景；时钟默认 24 小时并显示本机区域格式日期；仪表盘默认 PC CPU／内存，可选 PC／设备温度，缺失值显示“不可用”，过期值有文字标记。没有外部脚本、任意 XAML 或编辑器入口。

图片输入先检查 PNG IHDR／JPEG SOF、20MiB 文件及 2000 万像素上限，再核对 WPF 解码器报告的尺寸，并逐块读取像素暴露解码故障。Windows 素材存储通过 Core 的 IImageValidator 接入 Rendering 实现，不反向引用 Rendering。未验证素材只写临时文件，不提交正式素材。

画质尝试来自 DeviceSettings：默认 80→75→70，83→78→73→70，去重且最多四次。编码输出流限制为实际帧预算且不超过 1MiB；超限只转下一画质，不截断 JPEG 或改变尺寸。原始错误返回编号和操作建议。草稿 FrameContext 可无设备键；活动请求要求有效设备、会话代次和 V1 物理尺寸。
