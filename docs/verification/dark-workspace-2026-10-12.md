## 导航偏好与存储

应用设置新增可选 `NavigationLayout` 字段，保存为字符串 `Top` 或 `Side`，默认 `Top`。受支持配置缺字段或包含其他值时只对布局回退，其余设置继续读取，不因回退自动写文件；未知高版本文件仍由原存储兼容规则保护。

选择卡片立即更新内存中的布局预览；撤销预览只恢复最近确认的布局。完整撤销更改恢复应用设置编辑基线，不写设备配置。保存固定当前候选，成功后只更新已保存基线，保存期间的新编辑继续保留未保存标记；失败保留预览与错误，未知结果调用原核实流程而不重复写入。显式退出继续使用原保存／放弃／取消决策。

配置变化仅涉及 Core 应用偏好和 Windows 配置解析；设备、协议、渲染及保存协调器的控制逻辑保持现有实现。亮度新控件使用原 `BrightnessValue` 和 `ApplyBrightnessCommand`，不增加直接原生调用；整数与范围校验仍由现有命令执行条件和业务规则负责。

## 无设备 UI 运行入口

`--ui-only` 跳过设备协议附加、USB 发现、启动自动切换及设备电源事件生命周期。设备操作与重新检测不可用；离线内容编辑、偏好保存和诊断仍使用真实本地服务。普通启动保持现有行为。

首个 Release 输出已使用该参数启动。捕获窗口时桌面处于 Windows 锁屏，显示的是锁屏画面；已停止界面输入并请求解锁。该画面没有作为 WPF 截图保存或用作验收证据。本次创建的旧运行实例已结束；后续布局修正已编译至独立输出和常规 Release 目录，尚未运行。
