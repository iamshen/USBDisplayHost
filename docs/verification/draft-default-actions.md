# 草稿恢复默认代码基线

关联 REQ-04／REQ-06／REQ-08、FR-04／FR-06／FR-08、T-16／T-30，任务 7.6／8.2，依据 UI 规范第 4／5 节。

主题与设备设置的独立底部动作区已增加“恢复默认”。命令拒绝处理中、退出、只读／未知草稿保存状态，不绕过原保存保护；非法字段仍可通过该动作恢复为合法值。普通异常经现有错误编号处理，不释放工作区或关闭窗口。

主题恢复保持当前模板选择，字段值取自 Core ThemeContent.Default／DefaultClock／DefaultDashboard；清除编辑器图片引用但不删除素材文件，不释放活动／待保存候选引用。批量字段恢复后仅 UpdateDraft 一次，产生新修订并请求现有离线预览，不修改 savedRevision，不调用原用于已保存文件恢复的 Restore。原发送／保存结果继续对应冻结修订，新草稿标未应用。主题修订达到 long.MaxValue 时停止新修订／预览和后续写入，不回绕覆盖旧记录。

设备设置恢复取自 DeviceSettings.Default：0°、5fps、画质 80。仅修改待应用字段、产生一次草稿编辑；saved／savedRevision 和 LastSaveSucceeded 不因此变化。“撤销更改”仍回到原保存基线。DeviceSettings 不包含亮度，本动作没有亮度写入、默认亮度读回、EP0／HID、设备模式／电源命令或配置存储调用。

是否应用或保存由后续显式主动作决定，不因恢复默认自动发送。现有未知保存记录继续保护原冻结候选；恢复默认不放弃该记录，也不替代主文件核实。界面与设备设置实际应用入口仍受真实会话门禁控制。

目标 Release 构建四生产工程 0 警告、0 错误。未创建或运行测试、WPF 窗口、预览循环、文件写入或设备请求；仅有代码及编译证据。视觉 QA、草稿／应用交错和设备行为尚未运行验收，7.6／8.2 父项保持未完成。
