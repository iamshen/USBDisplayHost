关联：REQ-06／FR-06、REQ-08／FR-08、T-16／T-18、任务 6.6／7.5／9.3。日期：2026-10-08。

DeviceSettingsPage 已替换标题占位，使用 WPF XAML＋ViewModel 组合独立草稿存储。当前是明确标记的无设备离线草稿，选择方向 0／90／180／270°、帧率上限 1～5fps，输入 JPEG 画质 70～85 整数；默认 0°／5fps／80。提供保存、取消保存、撤销和重新读取，实际设备应用按钮保持不可用，没有伪造选定设备或发送行为。

保存冻结当前修订和字段，期间编辑仍可进行；成功只更新冻结保存基线，后续修改保留未保存状态。正常重新读取保留开始前或期间产生的编辑，提供重新读取的保存值作为撤销基线。保存未知时禁止继续写与撤销，但可继续编辑；“重新读取”转为核实本次冻结候选，独立“核实保存”按钮也仅执行读取。

核实必须主文件与冻结候选（设备归属、修订、全部设置）精确一致才清除待确认状态、更新保存基线。确认保存与是否还有新编辑分别判断，不要求用户撤销保存期间的新编辑。不匹配、备份、缺失、未知高版本、取消或普通异常均保留原候选与确认标识，不因读取完成放行下一次写入。未知高版本及修订达到限额保持只读。存储器明确返回 Cancelled 才视作已知取消；保存调用直接抛出取消异常时没有未提交证明，保守保留候选并提示核实。普通存储／页面初始化异常显示动作与错误编号。
