ThemePageViewModel 保存冻结草稿与 Candidate 素材租约。明确 Success 更新冻结修订保存基线，不抹掉期间编辑；明确 Failure／Cancelled 结束在途引用。Unknown 或已经进入写入调用后抛出普通异常／取消异常时，保留冻结草稿、独立确认标识和素材租约，状态显示保存结果待核实，暂停后续保存，不自动重写。导入和编辑仍可进行，不影响冻结候选；租约取得失败不进入写入。

页面提供“核实保存”，仅调用 LoadDraftAsync。只有 Primary 且完整草稿（设备归属、修订、主题字段）精确等于冻结候选才确认保存，释放未知候选引用；后续编辑保留，仍有新修改时继续显示未保存状态。备份匹配、文件缺失、其他有效草稿、未知高版本、读取故障或取消均不确认原保存，不再次写入；高版本仍拒绝后续写入。此入口不恢复字段、不发设备命令、不重放画面。

命令执行自身再次核对条件，不能绕过 UI 的 CanExecute 重复覆盖未知候选。页面停止等待保存、导入、初始化与核实调用，当前编辑引用随后释放；未确认保存引用不因普通停止自动丢弃。系统终止不弹阻塞决策，也不报告未知草稿已经保存。

普通退出即使 IsDirty 为 false，也检查未知保存。选择核实会先只读核实，仍未知则保留窗口；核实后仍有新编辑则另行保存新草稿。明确放弃以本次确认 Guid 为目标，仅丢弃冻结元数据与素材租约，不回滚已发生的文件写入；旧确认标识不能丢弃较新结果。
