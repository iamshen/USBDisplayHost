# 主题数据面初始化实施记录

关联：REQ-02／FR-02、REQ-03／FR-03、T-10、任务 4.5、TC-07／TC-23。日期：2026-10-08。

## 契约与初始化

Core `ThemeDataPlaneContract` 必须提供同版本固件和证据引用、vendor IN EP0 setup、完整响应长度、逐字节 ready 掩码／目标值、尺寸偏移与 16 位字节序、熄屏时查询安全性及颜色格式。查询必须由冻结记录明确保证只读，不以 IN 方向推断没有副作用。ready 至少有一个非尺寸字段，不进行 `response == 0x18` 或整个状态字节的未定义等值判断；尺寸另外读回并匹配已验证的 1920×1080 能力。

原路径支持契约描述的独立 16 位宽高字段。2026-10-09 根据 AD102 固件增加 status／EDID 双查询路径，见 `edid-query-baseline.md`；尺寸查询使用显式 DTD，不拼造单响应。没有默认接口号、ready 位、颜色值或兼容条目，构造契约本身不能证明样机已经支持它。

`ThemeDataPlaneInitializer` 核对当前操作、同固件验证能力、尺寸及亮度边界，然后执行 EP0 核验。亮屏分支还须先取得同设备／代次／操作／固件的 parser 清理收据，核实 ParserCleared、PreservedPowerIntent 和证据引用，才发送 AF 命令。EP0 ready 不代表 parser 清理，初始化类没有实现或假定清理方式。

On 分支依次发送 COLOR_FORMAT、WIDTH 高低字节、HEIGHT 高低字节、BACKLIGHT、AUTORLX=0、MJPEG=1、BLANK_MODE=1；每个命令检查实际请求和完整完成长度，再进入下一项。各命令前以及最后完成后核对当前操作。返回收据记录已完成命令数、查询核验和 On 序列完成，没有 JPEG 发送或设备呈现声明。

Off 分支不进入上述序列、不发送 JPEG。契约允许只读 Off 查询时仅核验 EP0；不允许查询时不进行任何数据面操作，返回 ProbeVerified=false／OnSequenceCompleted=false。这个结果仅记录执行范围及电源意图，不证明实际设备已熄屏、HID 可用或控制会话已经核实。

## 异常与所有权

一个初始化／Drain 执行中时立即拒绝新操作。任一步失败或取消都停止剩余命令，调用传输 Drain；不补偿、不亮屏重试、不发送失败序列的剩余部分。写调用开始后即使第一个命令失败也返回效果 Unknown；查询 Unknown 或 I/O 收敛未知同样保留 Unknown。仅查询已明确失败／不匹配且收敛成功才返回 Failure。普通异常记录编号并返回结果。

收敛未知时阻止下一次初始化，所属会话须持有传输所有者；显式 Drain 确认后仍须重新核实实际设备状态与 parser 清理，不会自动继续原序列。实际组合只能在物理会话所有者授予的帧边界运行，不得直接插入在途 JPEG。
