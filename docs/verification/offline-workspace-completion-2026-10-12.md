# 离线工作区补齐记录

日期：2026-10-12。关联 FR-01、FR-06、FR-07、FR-11，T-09、T-16、T-17、T-22、T-23；对应 OpenSpec 8.1、9.2、11.2、11.4、11.5。这里记录软件实现和编译，TC-01、TC-11、TC-13、TC-20～TC-22 的运行验收仍未完成。

## 实现结果

| 范围 | 软件行为 |
|---|---|
| 即时亮度 | 设备设置页提供 0～100 滑块、独立“设为 80”、已受理请求、实际读回及本地保存结果。设备页数值提交与滑块共用发送入口。一个在途目标加一个可替换待发目标，100ms 合并窗口；最终值在前一个目标确认并保存后执行。 |
| 亮度隔离 | 待发送值绑定设备键与会话代次；会话变化、取消、发送或保存失败停止队列。请求值由 Core 协调器受理时发布，读回值仅由观察结果更新。方向／帧率／画质的恢复默认不写亮度。仅本地重试复用现有保存通道。 |
| 启动发现与自动策略 | 普通启动读取设置后启动设备发现。默认不连接、不切模式。仅已保存启用自动切主题时，唯一且无歧义的设备可被选择、连接、核验，再按能力和电源执行一次切换；多台设备转交手动选择。拔插和休眠恢复不调用启动策略。 |
| 设置门禁 | 新启用启动／退出模式策略需当前连接 Ready、无在途操作、协议匹配、具备 SwitchMode 且 Power=On。已有选择可撤销；保存时 Core 再检查。SourceMatched 仍只是源码匹配，不表示实机已验证。 |
| 副屏切出提示 | 窗口及托盘切主题共用确认。提示 Windows 可能重排扩展屏上的窗口，支持“不再提示”。只有确认继续才保存该偏好，保存失败／未知不发送切换；取消不保存偏好。提示后复核设备键和代次。 |
| 兼容存储 | `ApplicationSettings.SuppressModeSwitchNotice` 为默认 false 的可选字段；旧文件缺字段继续提示。偏好与自启／其他设置共用串行保存、未知结果保护和核实流程，普通设置保存保留该字段。 |
| 状态刷新 | 工作区持有单个 1Hz 查询循环，隐藏窗口仍刷新；忙碌时跳过，不重叠。主题态经帧边界查询 HID／EP0，副屏仅查询 HID；结果回到同一协调器，不把缺失设备指标补为零。退出取消并等待原循环及请求。 |
| 切换超时 | 模式目标等待使用 8 秒预算，断线恢复使用 30 秒。模式等待结束后再做一次受限枚举，对同一设备重新连接核实；目标模式确认后返回协议连接结果，原模式核实可用返回切换未完成，不能核实返回 Unknown。不会发送补偿或第二条切换命令。 |
| 退出收敛 | 工作区停止时先停止并等待设备页的启动、亮度、状态查询及协议工作，再关闭设备会话及发现。状态观察已熄屏时不允许继续放行活动帧。 |

8 秒是进入超时核实阶段的等待预算，不表示本地已经测得切换 P95 或保证驱动调用在 8 秒结束；实际原生 I/O 仍按原所有权收敛。

## 剩余边界

- 安装更新 2.5、12.x 及相关发布工作本轮跳过；未接入 Velopack、未改变更新按钮或更新源。
- 固件 `b887bc1` 的设备温度、FPS、帧计数为占位字段，副屏缺少主题 Display 控制面，跨模式无法保持 Off。对应功能等待固件契约和设备联调，不编造字段或绕过电源限制。
- 副屏 HID 模式连接成功不等于 Windows 显示驱动目标路径可用；实际驱动与设备映射、桌面路径核实及完整目标就绪验收仍未完成。11.4／11.5 父项不勾选。
- 可选温度／风扇适配的支持硬件、权限及许可矩阵，真实拥塞降帧阈值、JPEG 接收／呈现、长稳与性能预算仍缺实测输入。
- 测试工程、测试代码、行为测试、应用运行、真实 WPF 截图、DPI／辅助技术、设备联调和发布验收均未执行。文档及编译不能替代这些证据。
