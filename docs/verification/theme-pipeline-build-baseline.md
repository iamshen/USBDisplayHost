# 主题管线组合创建代码基线

关联 REQ-01、D1／D3、T-09／T-10，任务 4.2／4.3。

ThemeConnectionSessionWork.CreatePipelineAsync 使用连接工作中实际打开的传输、控制观察器、parser、冻结能力及实测传输限额。调用方显式提供共享渲染器、配置／资产存储、设备设置、匹配固件的 JPEG 格式清单／完整解码验证器、帧率策略、指标读取及统一时钟，没有默认固件或模拟设备参数。

创建要求连接工作实际成功且 drain 已确认、协调器当前为同设备／代次的 Ready、无在途操作、无旧活动配置，并重验发现凭据。固件 JPEG 记录必须匹配已核实固件。连接工作只允许一次成功受理构建，重复创建不替换原图。

组合图依序创建共享帧率控制、带当前协调器门禁的 FrameTransferExecutor、FrameBoundaryScheduler、ThemeApplicationService、ActiveFrameProducer 及 ThemeSessionPipeline。执行器、调度器与生产者使用相同 TimeProvider；应用与动态帧共享同一个调度器、传输及编号来源。完整管线交接还要求它就是本连接工作创建的实例。

连接工作在最终实际控制读回匹配后，保留本次 ThemeInitializationReceipt 与 FrameParserRecoveryReceipt。On 管线在创建调度器／生产者之前，经 internal AdmitConnectionInitialization 向同设备／代次的未使用执行器转交就绪：要求已验证能力、固件一致、会话仍有效、非空同操作标识、parser 清理／保留电源意图证据、实际 probe／On 初始化完成和九条命令完整完成；执行器须无写入、无未确认 I/O 或保留缓冲。核验失败使管线构建失败，由原连接关闭链收敛，不绕过调度门禁。该转交只更新主机通道状态，不执行 USB、parser 或重复亮屏命令，不增加帧／字节计数；后续候选仍经过原 JPEG、身份、操作和电源门禁。Off 管线不执行此转交，继续 RecoveryRequired，不凭 Off 连接成功宣称允许发送。修复了已完成 On 连接初始化却创建出始终拒绝首帧执行器的代码链缺口；未取得实际首帧行为证据。

连接工作先持有构建对象，再启动后台构建，部分组件不会随失败结果丢失。构建失败通知原会话失效；未接管关闭等待构建结算，先停止已创建生产者与调度器，再确认原连接资源关闭。停止未知时保留构建对象、部分组件及全部依赖。共享渲染器、存储和指标来源继续由工作区持有，不由构建失败释放。

后台构建结果接续不在连接工作锁内回调协调器，避免与关闭／交接的锁顺序相反。成功构建不自动应用主题、恢复配置或提交活动 Profile，后续仍须由 Desktop 明确接管后执行真实应用；未接管期间协调器阻止新操作覆盖资源。

构建结束再次核验同设备／代次 Ready、无在途操作、发现凭据仍有效且未开始关闭。构建期间拔插或关闭后不返回成功管线；核验普通异常返回带错误编号的失败，并在释放连接工作锁之后通知原会话失效，由原所有者停止部分组件和关闭资源。交付后至 Desktop 接管之间仍由现有交接门禁再次核验，不能用构建成功替代交接确认。该竞态仅完成代码与编译检查，未执行拔插或并发运行验证。

App 尚未创建真实控制／parser 适配器或调用本入口，管线自动恢复、正式控制和完整桌面连接流程仍未完成。构造后台组件不是运行验收，也不能凭编译证明线程／资源行为。

Desktop DeviceSessionLifetime.CreateAndAttachAsync 串接上述工厂和原有 Attach 交接门禁，同时只允许一个构建在途，并计入工作区忙碌状态。构建失败保留原 typed 结果；构建成功而接管拒绝时，按管线实际协调器／设备键／代次通知失效，由原连接工作收敛，不直接 Dispose 其传输或控制句柄。普通异常提供错误编号。退出首先设置 stopping 门禁，再等待在途构建交接结算；退出期间构建完成会被 Attach 拒绝，不替换原会话。此等待只证明交接入口结算，原生资源的关闭确认仍由后续协调器关闭链负责，不能当作设备已释放。App 尚未调用这个入口，实际窗口、退出与拔插并发行为尚未验证。
