# 退出保存决策对话框实施记录

日期：2026-10-08。关联 REQ-07／FR-07、T-17、T-29、TC-13、TC-29、TC-30、TC-33，OpenSpec 3.2、9.3。

主窗口持有唯一 WPF UI 4.3.0 ContentDialogService 与覆盖工作区的 ContentDialogHost。应用设置、设备设置草稿、主题草稿和待保存恢复配置四类退出决策复用该服务。按钮为“保存后退出”“放弃并退出”“取消”，默认按钮为取消；正文换行并限定宽度。结果仅映射原有保存、放弃和取消流程，不将按钮受理当作保存成功，不增加设备重发或文件回滚。

窗口限制同时打开一个对话框，重复请求按取消返回，不建立等待队列。WindowExitService 仍保护唯一退出流程；系统结束会话先取消对话框等待，返回后再次检查系统退出状态，取消结果不启动普通保存流程。系统清理任务及其观察预算保持独立，取消提示失败只提交诊断。启动失败的无资源依赖窗口继续使用系统提示框后备路径。

主窗口的退出信息、错误和托盘不可用确认也复用该服务。信息提示使用“知道了”，托盘失败确认使用“退出”“保持窗口”，默认均为关闭／保留动作。关闭工作区失败后先启用窗口，再呈现错误，避免对话框随禁用窗口失去交互。呈现普通异常返回取消并尝试在工作区常驻错误中保留编号；常驻提示再次失败仅记录，不递归弹框。退出异常提示结束之前继续保留退出互斥标记；收托盘失败后的窗口恢复与提示也有独立二次异常边界。主窗口退出流程仅后备窗口分支仍使用 MessageBox，不扩展到启动入口、其他页面或原生托盘通知的统一。

实现 API 以本地锁定包 XML 与目标编译核对，包括 ContentDialogHost、ContentDialogService.SetDialogHost／ShowAsync、DefaultButton 和 ContentDialogResult。最终执行 `dotnet build src/UsbDisplayHost.Desktop/UsbDisplayHost.Desktop.csproj -c Release --no-restore`，四工程成功，0 警告、0 错误；差异检查通过。
