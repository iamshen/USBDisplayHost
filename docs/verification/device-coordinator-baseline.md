# 设备身份与单写者协调器实施状态

日期：2026-10-08。关联 REQ-01／FR-01、REQ-09／FR-09、T-09／T-11，OpenSpec 4.2、5.1。

## 身份与选择

Core DeviceSelectionResolver 接受当前发现列表及用户明确选择的 DeviceKey。按接口路径去重，同一路径的 VID／PID／序列号／容器冲突拒绝关联。持久键只由 VID 和序列号组成，PID 不进入设备键；多接口同序列号仅在容器一致时聚合，否则视为歧义，不自动接管另一台设备。软件处理上限为 1024 条输入／256 条不同路径，不是硬件支持数量声明。

DeviceSelection 只能由解析器产生。协调器选择后仅进入 Discovered，不自动打开接口、亮屏或发送。旧会话未断开或正在操作时拒绝换设备，须先等待工作及其资源收敛。现阶段原生句柄释放由之后的会话桥接用例负责；Core 的断连状态不能替代句柄已释放证据。

## 单写者与资源界限

DeviceCoordinator 的后台事件循环是 DeviceSnapshot 唯一写者。普通请求最多 16 条，满时明确拒绝；唤醒信号只有一个槽。已受理工作只有一个，完成事件另有专用槽，不能被采样或普通请求挤掉。断连／退出先处理，再接收完成。快照版本持续递增，会话代次在选择／离开时改变。

执行上下文固定设备键、代次、操作号、内容修订；主题与设备设置分别记录已受理修订高水位。旧设备／代次或更低修订请求被拒绝，迟到完成不恢复旧模式／电源／就绪状态。IsCurrent 在实际观察及断连待处理标记上再校验，供后续用例在发送／保存前使用。保存仍须使用受理设备键，不能在后台读取“当前选择”作为目标。

订阅最多 8 个，每订阅只有一个最新快照槽；注册时立即提供当前快照，取消订阅关闭该流。不通过订阅执行设备工作，不在快照发布时等待 UI 消费。

IDeviceSessionWork 负责业务及其资源，协调器只调度。Execute 结束后必调用 Drain，确认内核 I/O／取消回调收敛才释放互斥；用户取消回调只提交信号，原生取消通过后台 CancelAsync 执行。注销用户取消注册不在调度锁中等待回调，避免阻塞该回调提交。

无法确认收敛时保留工作所有者、锁存故障并拒绝后续操作；Dispose 不将未知清理报告为成功。失效会话的清理失败可阻止继续操作，但不把已断开的设备改回在线。非连接类工作仅抛取消异常时，执行结果归为待确认；用例应在能证明未产生作用时显式返回 Cancelled，不能用令牌取消证明设备未执行。

实际观察只有在设备键／当前接口身份、能力、驱动及状态维度有效时进入 Ready：主题尺寸须是经验证 1920×1080；副屏须有系统显示路径验证且没有主题推流；电源非 On 时不允许 Running。观察失败停止该会话，不猜测扩展能力或报告请求值已经生效。

## 当前证据与缺口

主题／设置应用工作已转交 Core 生成的 RejectionBeforeIo 凭据。只有明确 Failure／Cancelled、同一受理上下文、Drain 成功且就绪状态、亮度及活动配置保持受理前值时，协调器保留原会话并返回原失败／取消结果；不发布伪造设备观察。未知结果、其他动作和没有凭据的失败仍停流故障。实际状态读取／收敛适配器及工作区尚未组合，故无旧流续发的运行证据。

`./build.ps1 -Action Build` 四生产工程 Release 0 警告、0 错误；`git diff --check` 通过。未运行应用、模拟、测试或硬件操作。

协调器尚未接入 Desktop 组合根、PnP、WinUSB／HID、应用事务和真实设备用例；没有模拟器或虚构固件参数填充此接口。驱动／能力／显示路径布尔证据须由实际适配器验证产生，当前类型与守卫不能证明设备兼容。发现订阅顺序、句柄所有权、休眠、帧发送及恢复周期仍待后续任务。

身份歧义、取消／断连竞态、版本／修订隔离和资源增长尚无行为证据，4.2／5.1 父项保持未勾选。退出等待工作收敛尚未提供系统关机时限，不关闭 9.4。
