# 身份探测组合路由代码基线

关联 REQ-01／FR-01、D2、T-09、任务 4.2。

`CompositeDeviceInterfaceIdentityProbe` 接受 1～4 条显式接口 GUID 路由。GUID 不得为空或重复，没有默认 HID／WinUSB 路由，不根据路径文字猜测协议。成功创建转移探测器所有权；创建失败仍由调用方持有。相同实例可以服务多个路由，但只关闭一次。最多 8 个组合所有者，已经被组合入口持有的探测器不能再次接管。

入口串行探测，当前探测器从进入调用前一直保留到 drain 成功。访问失败、取消或异常后也必须收敛，不能覆盖当前所有者。未知身份结果阻止后续探测；明确非目标接口的成功 null 由实际探测器提供。未配置的 GUID 返回错误，不降级到其他协议探测。

关闭停止新请求，等待当前调用完成，先确认所有探测器收敛，再逐个释放。关闭任务缓存，不重复执行已经部分完成的释放；未知关闭强引用保留整个组合所有者及其探测器预约，后续 drain 返回未知。普通探测／释放异常转换为带错误编号的结果。同步驱动调用的有界退出仍未证明，未承诺致命 CLR／内存耗尽异常后继续运行。

该入口可作为 `WindowsDeviceDiscovery` 的身份探测依赖；尚未在 App 创建、注册或运行。路由和兼容记录需来自实际接口／固件证据。活动 WinUSB 身份复用代码见 `active-winusb-identity-baseline.md`，不能绕过共用路径预约重新初始化活动接口。
