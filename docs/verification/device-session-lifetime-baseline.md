# Desktop 会话退出实施记录

关联：REQ-08／FR-08、REQ-09／FR-09、T-13／T-21、任务 9.4。日期：2026-10-08。

App 组合根持有 DeviceSessionLifetime，并注入 ThemeWorkspaceLifetime。该生命周期只有一个会话所有者槽，已有所有者或开始退出后拒绝覆盖。CreateAndAttachAsync 已提供连接工作工厂到 Attach 的交接入口，等待在途构建并在拒绝接管时由原协调器收敛，详见 `theme-pipeline-build-baseline.md`。拒绝附加不能当作新管线已经安全关闭。当前应用没有附加真实管线。

ApplyThemeAsync／ApplySettingsAsync 已提供 Desktop 唯一会话所有者的应用入口：显式请求设备键和会话代次必须匹配当前 owner，冻结草稿的设备键也须相同；无 owner、构建在途、已有应用、关闭或退出时不受理。应用受理和关闭共用同一接管门禁，Core 管线已记录实际 operation 后才返回，后续关闭等待该操作结算。指标由调用方提供不可变快照，不查询设备或创建新的会话。入口不自动绑定无设备草稿到当前设备、不保存或改写草稿，不自动重试；原 ThemeSessionApplicationCompletion 完整转交，包括会话结果及独立的 ThemeApplicationAttempt。受理前普通异常返回 Failure 和错误编号；已受理任务的普通异常返回 Unknown，不能当作未发送或未保存。页面尚未调用这两个入口，首帧、并发编辑、保存失败及关闭交错行为尚未运行验证。

原生关闭任务共享且只执行一次。只有 ThemeSessionPipeline.CloseAsync 返回 Success 且 CanReleaseOwnership 为真才清除强引用；失败、未知、普通异常保留整条管线。未知原生关闭不自动重试或允许新会话替换，持续保留实际结果与错误编号；仅本地交接的明确失败可在处理待保存结果后再次核实。

显式退出在完成原有应用设置／主题草稿／设备设置草稿决策之后，先关闭设备会话，再停止页面命令、草稿预览、共享渲染、采样和日志。会话关闭未确认时显示原因、动作与原错误编号，恢复窗口可操作状态，不调用 Application.Shutdown；收至托盘不关闭会话。ThemeWorkspaceLifetime 自身也检查会话结果，未知时不释放这些共享资源，不记录 ResourcesStopped。

系统结束会话仍启动尽力清理，不能用异步任务代替操作系统退出期限；没有关机限时、退出切副屏授权或故障时的强制退出产品动作，不能声称阻止系统终止。普通显式退出检查与系统关机不是同一验收结论。

工作区关闭改为显式 StopAsync，返回 OperationResult，多个调用共享同一结果。命令 → 预览 → 渲染 → 采样 → 诊断页面 → 日志按依赖顺序停止；任一阶段普通异常返回 Unknown，保留后续资源并中断正常退出，不在异常被记录后报告整体停止成功。诊断页面和日志最后停止，使前面资源失败时仍能查询诊断。已经成功停止的资源不会自动重启，窗口恢复可操作状态不等于完整工作区恢复；失败结果不自动重试。

App 与系统结束会话路径使用同一个结果任务；普通显式退出必须检查工作区 StopAsync 为 Success，才卸载窗口关闭事件并调用 Shutdown。日志停止也参与结果，没有在日志释放之前预先记录整体 ResourcesStopped。

普通显式退出增加待保存设备恢复配置决策：设备应用／本地保存忙时保持窗口；有待保存候选时选择仅本地重试、明确放弃该 RetryId 或取消。Unknown 保存走原有主文件精确核实，不自动重写；非成功结果显示原错误并保留窗口。放弃不撤销设备画面或已经发生的文件写入。候选在关闭期间发生变化时，旧 RetryId 无权丢弃新候选。

原生关闭已确认、本地交接未处理属于明确 Failure，生命周期保留服务和待保存素材；可在处理本地结果后再次请求交接，原生关闭任务不重跑。Unknown 原生关闭仍缓存原结果，不自动重试或覆盖所有者。全部引用交接成功后才移除会话强引用。系统关机不弹上述决策，也不自动放弃待保存结果；系统实际终止仍受操作系统期限限制。
