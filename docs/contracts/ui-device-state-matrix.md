# 设备状态与界面操作矩阵

日期：2026-10-12。适用：AD102 V2 源码基线 `b887bc192d1ef45ebe40662aecfbcddfbb6e516d`，1920×1080，单台选定设备。依据：[协议接入](../verification/protocol-offline-integration.md)、[PRD](../02_PRD.md)、[UI 规范](../06_UI设计规范.md)。本表定义界面目标行为，不代表生产代码或样机已验证。

## 状态与优先级

连接、模式、电源、推流、待处理操作及本地保存分别显示。操作门禁按“不兼容／身份歧义 → 在途或未知结果 → 本地保存待处理 → 连接与能力 → 模式／电源／推流”判断；满足多个限制时采用最严格结果。新状态来自当前设备会话，不用按钮点击、历史预览或过期读回推断。

主题编辑只更新内存及预览，应用必须满足当前会话门禁；设备设置在可应用时开放，不提供草稿文件管理。操作取消只停止等待或请求取消，原生收敛及结果核实完成前不恢复冲突入口。

| 状态 | 页面事实 | 可用动作 | 禁用或隐藏 | 反馈与恢复 |
|---|---|---|---|---|
| 未发现设备 | 未连接，无在线预览 | 重新检测、离线编辑预览、诊断 | 应用、模式、电源、亮度、推流 | 有历史图时标“上次内容” |
| 发现多台／未确认选择 | 每台名称、身份后缀、模式、接口条件 | 选中候选、选择设备、重新检测 | 未明确选择前禁用连接；所有硬件写禁用 | 不自动接管第一台 |
| 身份歧义／不兼容 | 原因与错误编号 | 重新检测、诊断、主题编辑 | 连接或扩展写入按失败阶段拒绝 | 不能通过“重试”绕过能力校验 |
| 已选择／尚未连接 | 选定身份，未连接 | 连接、重新选择、主题编辑 | 应用及硬件控制 | 选择不等于连接 |
| 连接中 | 检测接口、读取状态、建立会话 | 取消等待、诊断、主题编辑 | 重复连接、换设备、应用及控制 | 不定进度；取消后显示核实／收敛状态 |
| THEME／On／运行 | 主题模式、已亮屏、推流中 | 亮度、应用主题／图像设置、暂停、熄屏、切副屏、断开 | 不展示恢复／唤醒为主要动作 | 主机预览与设备反馈分开 |
| THEME／On／暂停 | 已暂停，最后活动预览 | 恢复、亮度、熄屏、切副屏、断开、编辑预览 | 应用主题／图像设置 | 恢复继续活动配置，不发送未应用内容 |
| THEME／Off | 已熄屏，保留最后主机预览 | 显式唤醒、断开、编辑预览；亮度仅在当前能力及反馈有效时可调 | 应用、恢复推流、重复熄屏、模式切换 | “当前固件切换会亮屏，请先唤醒”；调亮度不等于唤醒 |
| SCREEN／On | 副屏模式已确认；桌面输出状态独立 | 切主题、断开、编辑预览、诊断 | 亮度、熄屏、唤醒、主题应用、暂停／恢复推流 | “当前副屏模式不支持此控制”；不打开主题 Display 通道 |
| SCREEN／Off 或电源未知 | 原样显示读回／未知 | 查询状态、诊断、断开、主题编辑 | 不能保证 Off 时拒绝切换；亮度／电源入口仍不可用 | 不提供无法执行的唤醒捷径；提示核实设备状态 |
| 切换中 | 原模式、目标模式、当前阶段 | 取消等待、诊断、主题编辑 | 重复／反向切换、设备选择、其他写入 | 先停产帧并收敛，再发一次命令，等待同设备目标接口 |
| 切换超时／结果未知 | 待确认，不改回原模式 | 核实状态、诊断 | 所有冲突写入及再次切换 | 8 秒等待后核实；目标满足则完成、原态可用则未完成、均未知则保留待确认 |
| 热拔插／休眠恢复中 | 正在恢复同一设备 | 停止等待、诊断、主题编辑 | 其他写入与设备自动接管 | 按原身份恢复，保留 Off，不自动切模式，不重放未应用内容 |
| 恢复失败 | 未连接或故障、编号与原因 | 重新检测、诊断、编辑预览 | 应用及设备写入 | 自动恢复有界；不循环重试或续传残帧 |
| 操作已确认／本地保存失败 | 设备结果＋本地未保存分别显示 | 仅重试本地保存、诊断、编辑主题 | 冲突写入依待处理保存门禁禁用 | 不重复发送主题、亮度或模式命令 |
| 本地保存结果未知 | 保存待核实 | 核实保存、诊断 | 重复保存同一候选与冲突写入 | 先只读核实，不能以取消宣称回滚 |
| 指标停更超过 3 秒 | 最后值＋“数据已过期” | 查看诊断、按独立控制状态操作 | 不把过期指标当新采样 | 温度／FPS 占位为“不可用”，不是 0 |

## 模式与电源的固件边界

THEME 的亮度／电源使用确认能力下的 Display 控制与读回；SCREEN 不具备该主题通道，HID 在线不授予亮度／电源能力。熄屏只使用纯电源控制，不使用复位、维护或 BLANK_MODE POWERDOWN。当前主机契约在 Off 时拒绝模式切换，不承诺跨模式保持熄屏。

“副屏模式已确认”表示同一设备目标 PID 与 HID 模式核实；“桌面输出可用”需要 Windows 驱动／显示路径的独立证据。没有该证据时显示“桌面输出待核实，由显示驱动负责”，不能以模式 ACK 或 PID 出现报告完整副屏就绪。

方向 0／90／180／270°由主机内容渲染应用，当前链路将固件旋转保持 0，最终帧仍为物理 1920×1080。帧率 1～5fps 和 JPEG 70～85是主机生成／发送参数，不冒充设备实际 FPS 或未实现的档位命令。

## 必须呈现的流程

1. 多设备：检测列表 → 选中候选 → 选择设备 → 连接 → 实际模式与能力；失败保留原因，不转控另一台。
2. 副屏切主题：首次提示“Windows 可能重新排列扩展屏上的窗口” → 切换／取消；“不再提示”属于应用偏好。取消不发命令；确认后核验目标会话与首帧条件。
3. 主题切副屏：收敛主题数据面 → 一次切换请求 → 重枚举与 HID 核实 → 单独展示桌面输出就绪证据；超时不反向补偿。
4. 熄屏／暂停：各自独立状态和恢复动作；恢复活动配置，不能把编辑预览视为应用。
5. 托盘：打开窗口、当前状态、切模式、暂停或恢复、退出。共用窗口命令门禁；普通关闭默认收托盘且不停止主题推流。
6. 显式退出：未保存应用设置提供保存／放弃／取消；主题及设备参数的未应用更改确认是否放弃；待确认保存单独核实或明确放弃。在途资源不收敛时保留窗口和错误。退出切副屏失败提供继续退出／重试／取消；继续退出仍需安全收敛。系统关机不弹阻塞对话框。

## 默认值与更新

| 项目 | 当前默认／边界 |
|---|---|
| 管理外观 | 深炭灰背景、实色分组面板；高对比度优先 |
| 导航 | 未保存偏好时默认 Side，保留已保存的 Top／Side；选择布局后预览，显式保存 |
| 设备模式策略 | 保持当前模式；自启、启动自动切主题、退出切副屏均关闭 |
| 窗口关闭 | 收至托盘 |
| 内容参数 | 图片模板、完整显示、0°、5fps 上限、JPEG 80；时钟 24 小时且显示日期 |
| 亮度 | 优先读回；首次协商必需且无法读取才采用 80；建议值可通过精确输入设置 |
| 自动检查更新 | 开启，自动尝试至少间隔 24 小时；不自动下载或安装 |
| 指标 | 时钟和基础指标 1Hz；缺失不可用，超过 3 秒过期 |

软件更新画板表达目标流程：未检查／检查中／有更新／下载／校验／待安装／安装准备／失败／新版本确认。服务未配置、离线、取消和结果未知有独立说明；不能把“尚未接入”的开发占位作为正式交付流程。安装仅更新上位机，交接前处理未保存内容并收敛设备操作；安装重启不执行自动模式切换策略。
