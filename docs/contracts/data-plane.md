Core ThemeDataPlaneContract 已要求显式固件与证据来源、只读 vendor IN 探测、ready 掩码和独立宽高字段；没有默认 request 或 ready 值。FrameFragmentPlan 的主机保护上限为单帧 1MiB、单次传输 245760 字节；这些上限及既有 AF 编码只代表主机实现，不证明设备兼容。实际限额取已核实设备与主机限额中的较小值。

parser 清理收据必须来自实际适配器，并绑定同设备、代次、操作、固件及电源意图。ResetPipe、SOFT_RESET 或写成功不能自行解释成 parser 清理完成。缺少清理及真实观察契约时，不创建假观察器或清理适配器，不开启 App 原生管线。

收到记录后先核对字段与已实现契约的兼容性，再实现对应适配器。证据不匹配则修订实现及协议说明，不能通过标记 Verified 跳过依据。任务 1.4 和设备行为验收保持未完成。
